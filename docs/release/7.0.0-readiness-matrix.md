# 7.0.0 readiness matrix

This matrix lists build and test entry points and release identities in the source tree. Release artifact checks are described in the [candidate report](7.0.0-candidate-report.md); deployment acceptance is in the [readiness checklist](7.0.0-readiness-checklist.md).

## Release workflows

| Workflow file under `.github/workflows/` | Trigger | Behavior |
| --- | --- | --- |
| `node-build.yml` | Push to `main`, pull request | Builds native dependencies and `paxd`, checks version and native digest, tests the kernel host and node packages, and runs native Python qualification. |
| `paxeer-release-check.yml` | Pull request on its declared paths, manual dispatch | Checks consensus-ledger coverage for pull requests, validates release identity, and compares reproducible builds. |
| `paxeer-release-publish.yml` | `paxeer-network/v*` tag push, manual dispatch with a tag | Validates tag identity, builds release assets, generates release notes and publishes the GitHub release. |
| `paxeer-docker-publish.yml` | Completion of Release Publish | On a successful tag-push publication, packages checksum-verified linux/amd64 release assets and records the container digest. |
| `docs-site.yml` | Documentation pull requests and pushes to `main` | Builds MkDocs with strict checks; pushes to `main` deploy to GitHub Pages. |

Package and application versions are defined separately in their manifests.
