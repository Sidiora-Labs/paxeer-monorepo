# Paxeer 7.0.2 release notes

Release date: 2026-11-19

Paxeer 7.0.2 replaces the 7.0.1 binary on every node without a new upgrade plan. It keeps plan
`v7.0`.

The release provides these behaviours:

- The fast execution path uses the ordinary path’s storage gas value of 20000 when the
  parameter holds no value.
- The virtual machine uses parameter-set defaults for unset decimal parameters in the current
  parameter set.
- The keeper of the fast path purges prefixes with the same metered range scan and deletion
  as the keeper of the ordinary path.
- A transaction result in the fast execution path carries its message log, events and codespace.
- The `eth` namespace returns block receipts matching the transactions listed in the block.
- `paxd applycheck` applies given transactions on independent copies of a stopped home through
  the sequencer, fast follower and ordinary follower forms and compares their results. With
  `--stand-in-receipt-key`, it uses an in-memory receipt key. With `--stand-in-credit`, it credits
  an account with a token inside each temporary copy before applying the transactions.
- The node reads its leader schedule from committed application state.
- A sequencing primary without a standby renews its lease after expiry, and a lease fence
  writes an error line.
- Opening a block releases held transactions whose nonce is next. A send without an open
  block returns an error before comparing its nonce.
- Held transactions use `sequencer.nonce-queue-lifetime`, which defaults to three seconds.
  A node with sequencing enabled logs the lease duration, nonce queue lifetime and per-sender
  and total queue limits in effect at startup.
