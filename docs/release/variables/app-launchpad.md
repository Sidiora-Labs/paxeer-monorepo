# Launchpad application variables

The Sidiora Launchpad application under `apps/launchpad` includes the Next web app and the React Native mobile app for Paxeer mainnet-beta, chain ID 125. These settings configure the application and its native build launchers.

Source paths below are relative to `apps/launchpad` unless they start with `apps/launchpad`; the short names `Info.plist` and `AndroidManifest.xml` refer to the mobile configuration files described below. Required means required by the indicated part: Android signing inputs apply to Android release tasks, iOS signing inputs apply to signed iOS releases, and the four `WEB_*_UPSTREAM` values apply to production web builds. The four required public backend origins have no application fallback in any mode. Browser variables prefixed `NEXT_PUBLIC_` are public bundle inputs and must never contain credentials. RPC overrides name HTTPS node roots; the source tries `NEXT_PUBLIC_RPC_URL`, `NEXT_PUBLIC_RPC_URL_FALLBACK`, then `NEXT_PUBLIC_PAXEER_RPC_URL`, deduplicating them and using `DEFAULT_PAXEER_RPC_URL` only when all three are unset.

Mobile public JSON is embedded in `mobile/ios/Sidiora/Info.plist`, root key `SidioraPublicConfiguration`, and in `mobile/android/app/src/main/AndroidManifest.xml`, section `application/meta-data` named `ag.sidiora.mobile.PUBLIC_CONFIGURATION`, key `android:value`. JSON rows below name the file, JSON section and key; the members of each optional object are required together when that object is enabled. The JSON contains public configuration only. `optionalFeatures` requires explicit booleans, even when a feature is disabled.

The root example is `apps/launchpad/.env.example`. Copy the web entries into `web/.env.local` for Next, and provide native inputs through the build environment or Xcode build settings. Native projects do not automatically load this example. Commented entries preserve an unset variable, framework-supplied values, or a source-derived default; host defaults are identified by source names rather than reproduced. In particular, RPC overrides and the development authority profile must remain unset when unused. `NEXT_PUBLIC_SENTRY_ENV` falls back only when unset; `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` enable the embedded wallet together. `SENTRY_ORG` and `SENTRY_PROJECT` identify source-map uploads when `SENTRY_AUTH_TOKEN` is supplied.
