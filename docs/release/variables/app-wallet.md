# Wallet application variables

The Paxeer wallet application in `apps/wallet` serves the wallet, account views and network surfaces as a Next.js application and PWA under `/wallet`. It uses the merged Paxeer network, with EVM chain ID `125`; the chain RPC, wallet gateway and other service endpoints have separate configuration names.

Source paths below are relative to `apps/wallet`. `NEXT_PUBLIC_*` settings are public and compiled into the browser bundle; the PWA build also reads service bases for network-only caching and the content security policy. Required settings enable the core wallet and account views. Optional integrations can require several settings together, as indicated in their rows. Defaults containing hosts, accounts, contract addresses or keys are identified by source name without reproducing their values. The root `.env.example` leaves those values empty, along with secrets and settings without defaults. An empty assignment is not always equivalent to an unset variable: omit unused `NEXT_PUBLIC_PAXEER_HOSTED_URL`. Leave `NEXT_PUBLIC_PNS_API_BASE` empty or unset to use the name helpers' same-origin default while omitting that base from PWA configuration.
