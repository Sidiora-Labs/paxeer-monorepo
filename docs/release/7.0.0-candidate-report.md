# Paxeer 7.0.0 candidate release report

Release `paxeer-network/v7.0.0` carries the `v7.0` merge plan. The kernel executes inside `paxd`; EVM chain ID is 125 (`0x7d`). A receipt is final when its block commits. The merge retains the anchor store for reads until the separately scheduled `v7.0-anchor-store-delete` plan.

## Release checks

The following source checks cover activation, migration and retirement. Run commands from the repository root after preparing the native dependencies with `make paxd-native-libs`.

| Coverage | Command |
| --- | --- |
| First sequenced block, export/import, activation, store deletion, bond returns and constructor refusal | `go test -v -count=1 -timeout 30m -run 'TestMergeRehearsalFirstSequencedBlock\|TestExportAfterMergeKeepsSequencerState\|TestMergePlanActivatesGatedPrecompiles\|TestAnchorStoreDeletedAtStep\|TestMergePlanReturnsGuarantorBonds\|TestMergePlanRefusesMissingMergeConstructors' ./node` |
| Retired anchor writes and selector refusals | `go test -v -count=1 -run 'TestRetiredWritesRevertAfterMerge\|TestEveryAnchorSelectorRetired' ./precompiles/layerxanchor` |
| Retired custody balance release | `go test -v -count=1 -run TestReleaseRetiredMovesEveryCustodiedBalanceToTheAuthority ./modules/layerxcustody/keeper` |
| Retired-caller inventory | `python3 tools/paxeer-x/tests/retired_callers_test.py` |
| ABI selectors, calldata, decoded results and refusal encodings | `python3 -m pytest -q tools/release/tests/test_programme.py` |
| Ordered merge rehearsal | `PYTHONPATH=spec/layerx-merge python3 -m pytest spec/layerx-merge/programme/tests/test_rehearsal_run.py::test_rehearsal_passes_on_merged_revision -q` |
| Pool-parity comparison rules | `bash -c 'source tools/release/tests/rehearse.test.sh; case_pool_parity_units'` |
| Consensus-commit coverage | `python3 tools/ci/consensus_commit_gate.py 68c8887a9520542d2878da3d6a44920ddd71b4b1 HEAD` |

The node rehearsal checks the first sequenced transaction's receipt sequence, state hash and balance. Export/import preserves sequencing state. The ordered rehearsal applies the merge, exports and reimports state, checks precompile activation, then applies anchor-store deletion.

ABI comparisons cover launchpad, perps, spot and pricefeed operations. Pool-parity unit checks cover pool counts, reserve caps and mismatch refusals; deployed pool comparison uses `tools/release/rehearsal/pool_parity.py` with a recorded halt-height state and an upgraded node.

## Release artifacts and deployment

`tools/release/build-paxd.sh` produces the linux/amd64 node, price sidecar, runtime libraries and checksums. `tools/release/reproducible-check.sh` compares independent builds. `tools/release/verify-release.sh` compares local artifacts with the published release. These checks address build identity and reproducibility; service readiness and network acceptance are deployment checks.

Use the [readiness checklist](7.0.0-readiness-checklist.md), [validator runbook](7.0.0-validator-runbook.md) and [service operator runbook](7.0.0-service-operator-runbook.md) for plan validation, staging, cutover and recovery.
