# Paxeer 7.0.0 systems

Paxeer runs one BFT network on EVM chain ID 125. The kernel executes inside paxd; sequencing and signed receipts share node state. Receipts are final when their blocks commit. Tenant domains are namespaces in the shared database.

The inventory records build commands, outputs, configuration, listeners, dependencies and documentation. Commands run from the repository root unless they include cd. Ports describe source defaults, deployment manifests or a named configurable listener.

new identifies a store or precompile activated by the v7.0 handler. changed identifies runtime or client behavior specified by the upgrade plan and service runbook. unchanged identifies systems with no change specified by those operations.

The anchor module retains archive reads until the separate anchor-store deletion plan. Verify and custody precompiles refuse calls at merge activation; anchor writes also refuse. Launchpad role contracts forward to the native precompile while preserving role storage, balances and nonces.
