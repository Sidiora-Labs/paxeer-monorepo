# Paxeer 7.0.1 release notes

Release date: 2026-11-14

Paxeer 7.0.1 replaces the 7.0.0 binary on every node without a new upgrade plan. It keeps plan
`v7.0`.

The release provides these behaviours:

- A node without sequencing applies a block with an EVM transaction from an address at its first
  use with the results of the sequencing node.
- The node’s deliver entry honours the trace switch.
- The tracing methods answer for blocks built by the sequencing node.
- A node with sequencing disabled forwards receipt requests when the forward URL is set.
- A pool configuration without an entry time limit is reported at construction.
