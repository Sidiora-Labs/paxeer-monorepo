# Paxeer 7.0.0 variables

This index links the variable inventories for the Paxeer 7.0.0 upgrade. Counts follow each page’s Required and Optional tables, including environment names, command inputs and configuration-file keys. The supply lists include required entries with no source default for at least one indicated reader, including rejected blank inputs; defaults in another mode or launcher do not supply that reader. Requirements apply to the named component, command, mode or enabled feature, and optional groups can become required together. Entries with documented defaults, including empty or derived defaults, remain on the linked page. Configuration names retain their file selectors, sections and keys; the linked pages explain path conventions and dependencies. Build tools and runtime supervisors supply their own inputs. Secret-file paths and public verification material are not secret values; protect private file contents. Names, purposes and secret classifications appear below without deployment values.
