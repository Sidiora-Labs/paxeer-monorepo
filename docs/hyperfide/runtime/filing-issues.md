# Reporting a problem

A useful report identifies the Hyperfide version, operating system, installation
method and provider version when relevant. Include the launch command, the
smallest sequence of steps that reproduces the behavior, the expected result
and the observed output.

For visual behavior, identify the screen and action involved. For performance
measurements, describe the workload and how the measurement was collected.
Remove credentials and personal information from commands and diagnostic output.

Source startup and configuration are described in
[configuration](configuration.md). [Debugging](debugging-and-qa.md) describes
runtime diagnostics and troubleshooting.
