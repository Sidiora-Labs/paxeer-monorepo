# Explorer Ethereum JSON-RPC contract

The explorer exposes Ethereum JSON-RPC at `POST /api/eth-rpc` and `POST /api/v1/eth-rpc`. [Explorer.EthRPC](../../../services/explorer/backend/apps/explorer/lib/explorer/eth_rpc.ex) reads indexed data or delegates execution-dependent methods to node JSON-RPC.
