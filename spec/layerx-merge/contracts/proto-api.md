# Proto API contract

The protobuf APIs define transaction messages, query requests and responses, service methods and HTTP annotations. Node registration and enabled listeners determine which services are reachable. The tables below link the schemas and current declarations; a schema declaration alone does not enable a listener.

The tables identify code declarations and configuration names. Activation, authentication and transport registration are defined by the linked implementations.
