# D54: KMS secp256k1 key kind for EVM sender handles

Block `[decision.54]` of spec.kvx at revision `2a1033aa2`. Generated from the merged specification; edit the fragment, not this file.

## Value

The internal KMS gains a secp256k1 key kind for EVM sender handles: handle prefix kms-secp256k1-, address = the last 20 bytes of keccak256 of the uncompressed public key, deterministic RFC 6979 ECDSA over a 32-byte prehash returning r, low s and the recovery id. Ed25519 stays the key kind for kernel identities, and every existing Ed25519 handle, request and response is unchanged.

## Basis

The KMS seals secp256k1 scalars (services/platform/hosted/internal/src/kms.rs:25).
