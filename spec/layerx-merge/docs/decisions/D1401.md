# D1401: sdk/js becomes a first-party package aligned to HEAD by hand

Block `[decision.1401]` of spec.kvx at revision `2a1033aa2`. Generated from the merged specification; edit the fragment, not this file.

## Value

sdk/js stops being a vendored snapshot in wave 0: its pin record is deleted and its provenance recorded in its README, because the snapshot ships only dist, its generate scripts name buf templates and a scripts directory that are not in the tree, and the protos it must follow live in this repository. From then on its three dist flavours are edited here to drop modules and fields no proto at HEAD declares and to add the fields HEAD declares, each edit with a node:test file under sdk/js/test. The programme domain updates the documents that list sdk/js as vendored (wiring.J53.1-3).

## Basis

CONTRIBUTING.md:19 forbids in-place edits of vendored snapshots, sdk/js/VENDOR.kvx:1-4 pins sdk/js, sdk/js/package.json:17-21 generate from buf templates absent from the tree, and consensus/proto/tendermint/types/types.proto:165-169 declares Proposal fields the snapshot lacks
