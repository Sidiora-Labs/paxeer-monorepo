# D223: Idempotency keys and 0x0906 stream ids are derived from the transaction

Block `[decision.223]` of spec.kvx at revision `2a1033aa2`. Generated from the merged specification; edit the fragment, not this file.

## Value

Writes whose ABI carries no idempotency key (budgetPull, budgetDelegateSpend, 0x0906 settle and close) and the 0x0906 stream id use sha256 domain-tagged digests of (tx hash, call ordinal, selector or payer), never zero.

## Basis

The encoders require an idempotency key the ABI does not supply (modules/layerxpay/types/payload_budget.go:123, :133) and the stream open encoder requires a nonzero stream id (modules/layerxpay/types/payload_stream.go:125).
