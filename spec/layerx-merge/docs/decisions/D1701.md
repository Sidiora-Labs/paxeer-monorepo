# D1701: 0x1015 is the perps venue

Source: `[decision.1701]` in [the installed specification](../../spec.kvx). Programme carry status: **kept**; source carry: `new`.

## Value

0x1015 serves the pure-Go perps module from v6.12.0; the layerxexchange keeper and precompile at the same address are legacy replay below that plan (decision.301).

`precompiles/perps/perps.go` declares `PerpsAddress` as 0x1015. `v6120StoreUpgrades` in `node/upgrades.go` adds the perps store, and `node/upgrades_v6120.go` declares the v6.12.0 plan.
