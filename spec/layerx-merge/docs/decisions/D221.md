# D221: The pay keeper runs on the shared kernel host; the layerxpay store keeps params only

Block `[decision.221]` of spec.kvx at revision `2a1033aa2`. Generated from the merged specification; edit the fragment, not this file.

## Value

The layerxpay keeper takes the one lxphost.Host the application builds over the shared host store key (decision.201) and reads and writes kernel records only through it; the layerxpay module store keeps ParamsKey 0x05 and KernelKVPrefix with the four family prefixes is not written by the keeper.

## Basis

The pay keys at modules/layerxpay/types/keys.go:20-28 address a kernel KV space inside the module store, while the kernel writes its records through the host context (modules/lxphost/ctx.go:292) and NewHost (modules/lxphost/host.go:600) has no production caller, so two copies of kernel state would diverge.
