# D824: Receipt protocol version selection retires; receipt keys are pinned

Block `[decision.824]` of spec.kvx at revision `2a1033aa2`. Generated from the merged specification; edit the fragment, not this file.

## Value

protocolVersion, requireProtocolVersion, SELECTABLE_PROTOCOL_VERSIONS and LAYERX_PROTOCOL_VERSION are removed from every middleware, conformance and example configuration; each verifier takes a receiptKeys list of pinned sequencer receipt key entries instead.

## Basis

requireProtocolVersion selects kernel receipt protocol versions at services/platform/middleware/seller/src/index.ts:159-169 and services/platform/examples/support/runtime.mjs:59-65 selects them for the reference applications; signed sequencer receipts carry no such version.
