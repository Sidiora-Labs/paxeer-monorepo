# D34: TEE signer threshold and key type

Source: `[decision.34]` in [the installed specification](../../spec.kvx). Programme carry status: **kept**; source carry: `kept`.

## Value

0x0907 verifies threshold signatures, 3 of 5, over secp256k1 attestor keys.

## Basis

`verifySignatures` in `modules/xweb/keeper/fulfil.go` recovers attestor signatures, checks membership and signer ordering, and enforces `AttestorSet.Threshold`.

## Carry-forward

The carried threshold is three of five secp256k1 attestor keys. `verifySignatures` checks membership, requires strictly ascending signer addresses and enforces the configured threshold. This decision does not establish production availability at 0x0907; [D1706](D1706.md) records the merge-table activation boundary.

## Affects

- 0x0907
- embedded wallet attestors
