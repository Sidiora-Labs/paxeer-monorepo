# D1525: lag_status under Autobahn measures execution behind consensus

Block `[decision.1525]` of spec.kvx at revision `2a1033aa2`. Generated from the merged specification; edit the fragment, not this file.

## Value

Under Autobahn CurrentHeight is the executed height from ABCIInfo, MaxPeerHeight is GigaRouter.LastCommittedBlockNumber and Lag is their gap, checked against Config.LagThreshold.

## Basis

LagStatus at consensus/internal/rpc/core/lag_status.go:10-34 compares BlockStore.Height with the block-sync peer height, and Status at consensus/internal/rpc/core/status.go:84-97 already treats the committed height as leading the executed height.
