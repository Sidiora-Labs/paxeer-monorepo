# D103: Snapshot keeps the idempotency count word at zero

Block `[decision.103]` of spec.kvx at revision `2a1033aa2`. Generated from the merged specification; edit the fragment, not this file.

## Value

lxp_snapshot_write keeps the u32 count word of the idempotency section and writes 0; lxp_snapshot_load refuses a nonzero count, so the snapshot layout keeps its offsets.

## Basis

src/state/lxp_snapshot.c:557-572 writes the count before the module rows; dropping the word would shift every later offset that src/state/lxp_snapshot.c:898-919 parses.
