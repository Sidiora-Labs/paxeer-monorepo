# D11: Program-origin web request terms

Carry status: `rewritten`.

Source: `[decision.11]` in [spec.kvx](../../spec.kvx). Carry status, code basis, bound tasks and any rewritten value come from [the carry-forward index](../../programme/data/decisions.kvx).

## Value

Program-origin (origin 2) web requests pay the kernel per-asset fee from the per-asset program fee account and the fee is split in equal shares among the signers, remainder to the first signer; origin-1 fees go to the xweb module account (decision.561, decision.1705).

## Code basis

Basis revision: `d90e6b8263ef3c6c4976fc5d0ee16ba20666b7db`.

splitProgramFee pays equal shares and the remainder to the first signer (modules/xweb/keeper/program_fulfil.go:191). ProgramFeeDenom resolves the per-asset denomination (modules/xweb/keeper/program_denom.go:16); origin-1 payment uses SendCoins to the module account (modules/xweb/keeper/request.go:59).
