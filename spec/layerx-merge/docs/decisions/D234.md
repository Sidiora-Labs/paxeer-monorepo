# D234: 0x101B logs are packed from call arguments and post-call kernel records

Block `[decision.234]` of spec.kvx at revision `2a1033aa2`. Generated from the merged specification; edit the fragment, not this file.

## Value

Each 0x101B write emits its event after HostExecute commits, taking indexed ids from the call arguments and amounts from the kernel record read back through the host.

## Basis

The kernel returns a receipt without event payloads (modules/lxphost/host.go:574) and the precompile events are logged by pcommon.EmitEVMLog (precompiles/common/evm_events.go:16).
