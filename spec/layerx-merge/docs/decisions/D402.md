# D402: Surface reverts use Launch-x custom-error selectors; keeper-only errors use Error(string)

Block `[decision.402]` of spec.kvx at revision `2a1033aa2`. Generated from the merged specification; edit the fragment, not this file.

## Value

A launchpad keeper error that maps to a Launch-x custom error reverts with that selector and ABI arguments at every role surface; the seven keeper-only errors (codes 2, 22, 24, 25, 26, 29, 30) revert with Error(string) carrying the registered LXP_LAUNCHPAD_ text. This supersedes the stale rule that every launchpad refusal reverts as Error(string) with an LXP code.
