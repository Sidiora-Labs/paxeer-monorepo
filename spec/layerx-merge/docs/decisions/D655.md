# D655: Origin-2 fees stay in the per-asset web fee accounts

Block `[decision.655]` of spec.kvx at revision `2a1033aa2`. Generated from the merged specification; edit the fragment, not this file.

## Value

A program request fee stays in the web fee account of its asset until FulfilProgram splits it; no module escrow and no refund path is added.

## Basis

ProgramFeeAccount derives one account per asset (modules/xweb/keeper/program.go:146-158) and RequestFromProgram documents that the fee stays there with no refund (modules/xweb/keeper/program.go:174-191).
