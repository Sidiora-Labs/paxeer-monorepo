# D802: Faucet funding stays on the faucet, testnet-control and core boundary chain

Block `[decision.802]` of spec.kvx at revision `2a1033aa2`. Generated from the merged specification; edit the fragment, not this file.

## Value

px_requestFunds keeps the claim path of the gateway faucet module; the gateway never signs. The bank send is made by the core boundary treasury sender (task 8.10.1), reached through the testnet control service, so the faucet service and its funding contract are unchanged.

## Basis

The faucet posts claims to LAYERX_TESTNET_FUNDING_URL (services/platform/hosted/faucet/src/main.rs:310) and the testnet control forwards /admin/v1/testnet/fund to the core boundary (services/platform/hosted/testnet/src/main.rs:1235-1262); the stale plan had the faucet sign itself.
