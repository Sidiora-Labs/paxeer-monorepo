# D733: Logs subscription lifetime

Block `[decision.733]` of spec.kvx at revision `2a1033aa2`. Generated from the merged specification; edit the fragment, not this file.

## Value

A logs subscription lives until the client unsubscribes or the connection closes (rpcSub.Err()), on a context owned by the subscription; the polling goroutine no longer waits on the eth_subscribe call context, so its lifetime is neither one poll (HEAD) nor unbounded. The live count stays capped by evm.max_subscriptions_logs (task 7.10.5).

## Basis

rpc/subscribe.go:316 waits on ctx.Done() of the call context, which startCallProc cancels when the call returns (core/deps/geth/rpc/handler.go:387-389); notifyReceiptedLogs ends on sub.Err() at rpc/subscribe.go:355; TestSubscribeNewLogs is skipped at rpc/subscribe_test.go:224
