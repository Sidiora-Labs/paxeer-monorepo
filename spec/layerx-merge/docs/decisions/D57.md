# D57: CosmWasm transaction counter is the block position from the merge plan height

Block `[decision.57]` of spec.kvx at revision `2a1033aa2`. Generated from the merged specification; edit the fragment, not this file.

## Value

From the height the merge plan is done, every path that executes a transaction at a block position (App.DeliverTx for the synchronous, concurrent and sequencer paths, and the Giga per-transaction deliver function) sets the CosmWasm transaction counter to that position, so env.transaction.index of a contract is the transaction's index in the sealed block at the sequencer and at every validator; before that height no path sets it, as on the existing code, so historical blocks replay unchanged. SetTxPosition only places the context; the counter is set inside the deliver path.

## Basis

The per-transaction deliver paths are node/abci.go:169 and node/abci.go:230.
