# D8: Trading semantics where kernel and exchange differ

Carry status: `rewritten`.

Source: `[decision.8]` in [spec.kvx](../../spec.kvx). Carry status, code basis, bound tasks and any rewritten value come from [the carry-forward index](../../programme/data/decisions.kvx).

## Value

Kernel books keep capacity 256 with 8 fills per dispatch and spot settlement requests stay refused in the kernel; the served venues are perps at 0x1015 (decision.301) and spot on PECOR at 0x1021-0x1025 (decision.334), whose order ids and fees follow their own modules; launchpad fees accumulate per market.

## Code basis

Basis revision: `d90e6b8263ef3c6c4976fc5d0ee16ba20666b7db`.

Kernel caps are LX_PERPS_BOOK_CAPACITY = 256 (include/layerx/lx_perps.h:27) and LX_PERPS_DISPATCH_MAX_FILLS = 8 (include/layerx/lx_perps.h:34). Spot addresses run from PECORAddress (modules/spot/types/keys.go:14) to PECORVaultAddress (modules/spot/types/keys.go:26); the launchpad swap records FeeRecorded (modules/launchpad/keeper/swap.go:32).
