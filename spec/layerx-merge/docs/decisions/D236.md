# D236: Kernel authority comes from the caller's 0x1004 binding, with no signature

Block `[decision.236]` of spec.kvx at revision `2a1033aa2`. Generated from the merged specification; edit the fragment, not this file.

## Value

The pay keeper resolves the acting kernel identity from GetLayerXDid of msg.sender; an unbound caller is refused with ErrUnboundCaller and no ed25519 signature is carried in the call.

## Basis

GetLayerXDid maps an EVM address to its did:layerx key (modules/evm/keeper/layerx_binding.go:18) and the host authority type carries the identity only (modules/lxphost/host.go:568).
