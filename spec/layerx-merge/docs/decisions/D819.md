# D819: The hosted node launcher stays until a merged-chain pod replaces it

Block `[decision.819]` of spec.kvx at revision `2a1033aa2`. Generated from the merged specification; edit the fragment, not this file.

## Value

This card deletes the kernel node test drivers, the guarantor launcher and the custody provisioning, but keeps bootstrap.sh, supervisor.sh and sequencer-env.sh because the node pod still runs them; replacing the pod's layerxd container with the paxd deployment is a separate change this card does not schedule.

## Basis

The node pod runs layerxd through the supervisor (services/platform/hosted/node/deployment.yaml:186-189) while the merged chain node is deployed separately (services/platform/hosted/paxeer/deployment.yaml:1).
