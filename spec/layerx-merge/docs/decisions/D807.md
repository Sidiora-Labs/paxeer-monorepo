# D807: Agent-boundary receipt identifiers are EVM transaction hashes

Block `[decision.807]` of spec.kvx at revision `2a1033aa2`. Generated from the merged specification; edit the fragment, not this file.

## Value

After the merge an activity is an EVM transaction, so GET /v1/receipts/{id} and /internal/v1/receipts/{id} take the 32-byte transaction hash and answer the pax_sequencerReceipt receipt for it; the route shapes and the 32-byte hex rule are unchanged.

## Basis

receipt_route parses a 32-byte hex id (services/platform/hosted/agent-boundary/src/main.rs:1809) and pax_sequencerReceipt takes a transaction hash (rpc/sequencer_receipt.go:232).
