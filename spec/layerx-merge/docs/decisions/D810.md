# D810: Testnet funding pays the EVM address bound to the funded DID

Block `[decision.810]` of spec.kvx at revision `2a1033aa2`. Generated from the merged specification; edit the fragment, not this file.

## Value

The core boundary funds the address addr getEvmAddrByLayerX answers for the DID's key, so the fund command keeps its fields and the faucet and testnet control are unchanged; a DID without a binding is refused, not funded natively.

## Basis

FundingCommand carries did and public_key only (services/platform/hosted/core/src/main.rs:127-132) and the gateway resolves bindings through 0x1004 (services/platform/hosted/gateway/src/evm.rs:60).
