# D923: layerx-client keeps the node JSON-RPC client and retires the LNI kernel client modules

Block `[decision.923]` of spec.kvx at revision `2a1033aa2`. Generated from the merged specification; edit the fragment, not this file.

## Value

layerx-client keeps account_binding, paxeer_binding, sequencer, budget, grants and runtime_clock, adds px and subscription, rebases read, payments, receipt, stream, submit, batch, withdrawal, evidence and ai_market onto SequencerEndpoint, and deletes lni, client, head, resolver, handover, handover_policy, availability, caps, execution_prestate, arbiter_admission, arbiter_prestate and the evidence submodules caps, execution_prestate, arbiter_admission and arbiter_prestate, because every one of them reads kernel frames through FrameTransport, which the node no longer serves.

## Basis

services/agent/crates/layerx-client/src/lni/transport.rs:122 defines FrameTransport, the only transport of services/agent/crates/layerx-client/src/read.rs:304 and services/agent/crates/layerx-client/src/submit.rs:183; services/agent/crates/layerx-client/src/sequencer.rs:197 is the node JSON-RPC client and spec/layerx-merge/contracts/clients.md:197 maps lx_sendActivity to eth_sendRawTransaction; the stale spec kept the LNI client as a compatibility path.
