# D363: The spot user order index is append-only

Block `[decision.363]` of spec.kvx at revision `2a1033aa2`. Generated from the merged specification; edit the fragment, not this file.

## Value

Placing an order writes a UserOrder entry that is never deleted, so GetUserLimitOrders and the stop-order user lists return every order id a user has placed; the programme keeps that history and adds no pruning task, while the active lists that EndBlock walks become constant-cost in task 3.22.2.

## Basis

modules/spot/keeper/orders.go:419 writes the UserOrder entry, modules/spot/keeper/orders.go:156-175 iterates it without a status filter and modules/spot/keeper/stoporders.go:233-234 writes the stop-order entry
