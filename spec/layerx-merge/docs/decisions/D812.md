# D812: Hosted readers pin receipt keys from a file, not from checkpoints

Block `[decision.812]` of spec.kvx at revision `2a1033aa2`. Generated from the merged specification; edit the fragment, not this file.

## Value

The receipt authority and agent boundary verify receipts against a pinned ReceiptKeyList file, as the gateway does, instead of a sequencer history rebuilt from kernel checkpoints; rotation is a file change and restart.

## Basis

The gateway loads ReceiptKeyList from a file (services/platform/hosted/gateway/src/lib.rs:1295-1330) while the authority rebuilds history over the kernel socket (services/platform/hosted/authority/src/trust.rs:128).
