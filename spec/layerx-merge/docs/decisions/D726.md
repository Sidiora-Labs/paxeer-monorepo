# D726: Denom-valued REST routes gain query-string bindings

Block `[decision.726]` of spec.kvx at revision `2a1033aa2`. Generated from the merged specification; edit the fragment, not this file.

## Value

Routes whose path variable is a bank denom keep the path form and gain an additional binding that takes denom from the query string; this covers bank SupplyOf and DenomMetadata and tokenfactory DenomAuthorityMetadata and DenomPaused. The oracle ExchangeRate route keeps the path form only.

## Basis

grpc-gateway v1.16.0 (go.mod:48) binds {denom} to one segment, see pattern_Query_SupplyOf_0 at sdk/x/bank/types/query.pb.gw.go:853 and pattern_Query_DenomAuthorityMetadata_0 at modules/tokenfactory/types/query.pb.gw.go:520, while factory denoms contain slashes (modules/tokenfactory/types/denoms.go:26)
