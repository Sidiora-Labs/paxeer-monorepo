## Value

The paxai worker's model runner (task 0.149) executes the engine pinned inside each (model, deployment) directory under PAXAI_RUNNER_MODELS; the repository bundles no inference engine and no model weights, so a gate host with an empty model directory exercises the recorded CapabilityMismatch path and the real engine path is exercised only where a pinned model directory is provisioned. The choice of engine and the first provisioned models are an operator decision recorded when they are provisioned.
