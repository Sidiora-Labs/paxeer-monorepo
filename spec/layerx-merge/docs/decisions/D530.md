# D530: Fencing travels in the replication ack

Block `[decision.530]` of spec.kvx at revision `2a1033aa2`. Generated from the merged specification; edit the fragment, not this file.

## Value

A host that took a later lease answers every group with AckRefused and its epoch; the primary turns that into ErrFenced and stops; Ack.Epoch is zero on every other answer.

## Basis

Ack at node/sequencer/standby.go:64-74 has no epoch and receive at node/sequencer/standby.go:616-653 accepts any continuous group, so a promoted standby would keep taking the old primary's ACCEPTs.
