# D15: Sequencer receipt signing key

Carry status: **kept**.

Carry-forward index: `programme/data/decisions.kvx` `[decision.15]`.

## Value

Receipts are signed by a separate ed25519 receipt key per sequencer host, distinct from the validator key and pinned in the authority service and the settle endpoint.
