# D15: Sequencer receipt signing key

Block `[decision.15]` of spec.kvx at revision `2a1033aa2`. Generated from the merged specification; edit the fragment, not this file.

## Value

Receipts are signed by a separate ed25519 receipt key per sequencer host, distinct from the validator key and pinned in the authority service and the settle endpoint.

## Basis

The receipt verifier takes a pinned ed25519 key (services/agent/crates/layerx-proof/src/receipt.rs:273); primary and standby keys may overlap per host (modules/sequencer/keeper/receipt_keys.go:75).
