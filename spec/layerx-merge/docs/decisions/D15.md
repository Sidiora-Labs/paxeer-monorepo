# D15: Sequencer receipt signing key

Carry status: `kept`.

Source: `[decision.15]` in [spec.kvx](../../spec.kvx). Carry status, code basis, bound tasks and any rewritten value come from [the carry-forward index](../../programme/data/decisions.kvx).

## Value

Receipts are signed by a separate ed25519 receipt key per sequencer host, distinct from the validator key and pinned in the authority service and the settle endpoint.

## Code basis

Basis revision: `d90e6b8263ef3c6c4976fc5d0ee16ba20666b7db`.

ReceiptKeys is the governed list of pinned receipt keys; primary and standby host key ranges may overlap (modules/sequencer/keeper/receipt_keys.go:77).
