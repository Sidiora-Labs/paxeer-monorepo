# D1702: pricefeed 0x1020 is the price source

Source: `[decision.1702]` in [the installed specification](../../spec.kvx). Programme carry status: **kept**; source carry: `new`.

## Value

pricefeed at 0x1020 is the price source of the perps and spot venues from v6.12.0; the stale exchange pushOracle path is void (decision.304).

## Basis

`precompiles/pricefeed/pricefeed.go` declares `PriceFeedAddress` as 0x1020. `node/upgrades_v6120.go` includes pricefeed in `v6120NewModules` and initializes it through the upgrade plan.

## Carry-forward

Perps and spot read prices through the v6.12.0 pricefeed venue at 0x1020. The stale exchange `pushOracle` path is void under decision.304; it is not the venue price source.
