# D801: px_getReceiptKeys answers the gateway's pinned receipt key list

Block `[decision.801]` of spec.kvx at revision `2a1033aa2`. Generated from the merged specification; edit the fragment, not this file.

## Value

The router answers px_getReceiptKeys from the list loaded from LAYERX_GATEWAY_RECEIPT_KEYS_FILE, the same ReceiptKeyList the settlement verifier uses, so router and clients verify receipts against one list; the list loads without kernel backends.

## Basis

ReceiptKeyList is defined at services/platform/hosted/gateway/src/lib.rs:1295 and loaded only inside the kernel backend block at services/platform/hosted/gateway/src/main.rs:1021-1033; no router method serves it at HEAD.
