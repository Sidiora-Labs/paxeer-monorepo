# D206: The EVM DID binding replaces the envelope signature

Block `[decision.206]` of spec.kvx at revision `2a1033aa2`. Generated from the merged specification; edit the fragment, not this file.

## Value

On the EVM path the actor is the DID bound to the caller through 0x1004; the host passes a binding flag in KernelAuthority so the kernel skips the ed25519 envelope signature check while keeping the controller, key and context checks.

## Basis

The kernel verifies the envelope signature at src/modules/asset/lx_asset_execution.h:184 and the host writes the authority at modules/lxphost/host.go:229; bindings are kept by modules/evm/keeper/layerx_binding.go:18-56.
