# D1325: Sandbox expiry and retirement events are logged only inside 0x101D calls

Block `[decision.1325]` of spec.kvx at revision `2a1033aa2`. Generated from the merged specification; edit the fragment, not this file.

## Value

SandboxDestroyed and StorageRetired EVM logs are emitted only when the kernel events 0x090A or 0x090B appear in the receipt of a 0x101D call; expiries the kernel runs outside a call produce no EVM log.

## Basis

src/modules/programs/sandbox_expiry.c:317 emits 0x090A from the expiry path and no end-block path calls pcommon.EmitEVMLog (precompiles/common/evm_events.go:16).
