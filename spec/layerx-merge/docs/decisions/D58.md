# D58: Stream rate change is activity ordinal 8 end to end

Block `[decision.58]` of spec.kvx at revision `2a1033aa2`. Generated from the merged specification; edit the fragment, not this file.

## Value

Stream rate change is activity ordinal 8 in every layer: the stream result codec stores and loads ordinals 1 through 8 with the existing result layout, module_execute passes ordinal 8 to stream_execute_typed, the stored result of a rate change carries ordinal 8 and its replay returns that result, and a key stored for another ordinal or stream returns LXP_ERR_CONTEXT_MISMATCH in validate and in execute; lifecycle_load is exported and shared rather than copied. The test assertion that execute refuses ordinal 8 with LXP_ERR_UNKNOWN_ACTIVITY described the state before the rate change executed and is replaced by acceptance assertions, a spec correction and not a weakening.
