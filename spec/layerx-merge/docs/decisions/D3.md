# D3: Home of session keys and delegated authorities

Carry status: `kept`.

Source: `[decision.3]` in [spec.kvx](../../spec.kvx). Carry status, code basis, bound tasks and any rewritten value come from [the carry-forward index](../../programme/data/decisions.kvx).

## Value

Session keys and delegated capabilities are authz grants carrying a LayerX-scope Authorization that covers kernel and program calls, keeping all eight authority kinds.

## Code basis

Basis revision: `d90e6b8263ef3c6c4976fc5d0ee16ba20666b7db`.

The kernel defines eight authority kinds, from LXP_AUTHORITY_OWNER (include/layerx/lxp_authority.h:12) through LXP_AUTHORITY_KIND_TIMELOCK (include/layerx/lxp_authority.h:19), including LXP_AUTHORITY_SESSION_KEY (include/layerx/lxp_authority.h:13).
