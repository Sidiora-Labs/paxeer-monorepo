# D56: addr 0x1004 revert reasons use the registry LXP_ADDR codes

Block `[decision.56]` of spec.kvx at revision `2a1033aa2`. Generated from the merged specification; edit the fragment, not this file.

## Value

addr 0x1004 emits the LXP_ADDR_* codes of the address-table registry (section (b)) for its refusals: LXP_ADDR_EVM_NOT_BOUND for getLayerXDid of an unbound address and the eight LXP_ADDR_LAYERX_* codes for binding errors; the kernel codes LXP_UNKNOWN_DID, LXP_BAD_SIGNATURE, LXP_DUPLICATE_ENTRY, LXP_SEQUENCE_EXHAUSTED and LXP_NON_CANONICAL are not used at this address.
