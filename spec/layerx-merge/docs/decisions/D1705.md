# D1705: xweb fee destinations by origin

Source: `[decision.1705]` in [the installed specification](../../spec.kvx). Programme carry status: **kept**; source carry: `new`.

## Value

Origin-1 web fees are paid into the xweb module account; origin-2 fees are paid from the per-asset program fee account to the signers' payout accounts in equal shares, remainder to the first signer (decision.561).

## Basis

`Request` in `modules/xweb/keeper/request.go` transfers origin-1 payment into the module account. `splitProgramFee` in `modules/xweb/keeper/program_fulfil.go` pays origin-2 fees from the recorded fee account to registered signer payouts, with the integer remainder paid to the first signer.

## Carry-forward

For origin 1, request payment enters the xweb module account. For origin 2, `splitProgramFee` uses the recorded per-asset program fee account and pays each signer’s registered payout account. Each share is floor(amount / signer count); the remainder goes to the first signer, which is the lowest address in canonical signer order. A zero share sends no coins (decision.561).
