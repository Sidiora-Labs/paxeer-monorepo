# D227: Agent end-block gas is capped by MaxBlockGas and counted in block gas

Block `[decision.227]` of spec.kvx at revision `2a1033aa2`. Generated from the merged specification; edit the fragment, not this file.

## Value

Params.MaxBlockGas defaults to 30000000 and bounds the summed GasLimit of the jobs admitted per height; RunDue returns the gas used and the legacy end block adds it to blockGasUsed before the EVM end block.

## Basis

EndBlocker caps only the job count (modules/layerxagent/keeper/scheduler.go:31-36) and runs each job on an infinite gas meter (modules/layerxagent/keeper/scheduler.go:99), so 64 jobs of 10000000 gas (modules/layerxagent/keeper/keeper.go:40-41) are unaccounted for at node/legacyabci/end_block.go:42.
