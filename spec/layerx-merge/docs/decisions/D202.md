# D202: Idempotency is kernel-owned

Block `[decision.202]` of spec.kvx at revision `2a1033aa2`. Generated from the merged specification; edit the fragment, not this file.

## Value

Idempotency records live in the host store under prefix 0x04 and are pruned by the kernel; the keeper-level IdempotencyPrefix, IdempotencyBySequencePrefix, IdempotencyKey and IdempotencyBySequenceKey are retired and IdempotencyRetention reaches the kernel through a host setter.

## Basis

The host writes idempotency entries at modules/lxphost/ctx.go:281 and the kernel prunes them at src/state/lxp_idempotency.c:128 from the retention field of include/layerx/lxp_state.h:42; the module keys at modules/layerxauth/types/keys.go:21-35 are used only by a test.
