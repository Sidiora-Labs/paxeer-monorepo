Source: `[decision.2]` in [spec.kvx](../../spec.kvx). Carry status, code basis, bound tasks and any rewritten value come from [the carry-forward index](../../programme/data/decisions.kvx).

## Value

Kernel accounts become derived bank addresses per DID and sub-account suffix; perps margin is not in that namespace: the perps module holds margin accounts of EVM addresses itself.
