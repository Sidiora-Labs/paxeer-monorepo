# D2: Kernel account and margin model

Carry status: `rewritten`.

Source: `[decision.2]` in [spec.kvx](../../spec.kvx), with code basis at revision `2a1033aa2`. Carry status and bound tasks come from [the carry-forward index](../../programme/data/decisions.kvx).

## Value

Kernel accounts become derived bank addresses per DID and sub-account suffix; perps margin is not in that namespace: the perps module holds margin accounts of EVM addresses itself.

## HEAD basis

Kernel accounts carry a sub-account kind and parent account id (include/layerx/lxp_genesis.h:148-149); perps deposits credit an EVM address account in modules/perps/keeper/account.go:54.
