# Issue 1695: [Coherence] The production indexer still mounts RegisterStatus without a mode, delivery health or dead-letter policy, so every production GET /status now answers 503 unavailable

## Defect and impact

RegisterStatus now treats an empty Mode as a failure (it adds "mode" to unavailableComponents, nulls lastProcessedBlock and returns 503). The only production caller in app.go was not changed: it still passes just Store, ChainID, Publisher and StartTime. A healthy production indexer therefore always reports status "unavailable" with no block height, and both dead-letter routes return 503. The only record of the needed app.go wiring is the repair record's own wiring line. No spec task covers it: StatusCanonical and MaxDeliveryLag do not appear in spec.kvx.

Kind: connective. Severity: major.
