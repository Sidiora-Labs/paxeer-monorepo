# Issue 1538: [Coherence] The acceptance contract of 22.9.33.1 still names --test serve_routes under -p layerx-agentd, the command the commit corrected elsewhere

## Defect and impact

The commit moves the serve_routes test target under -p layerx-agentd-host in task 22.9.33's build_cmd and verify_cmd and in requirement 22047's verification_contract. The acceptance block acceptance.22.9.33.1 still uses the old command, which cargo refuses because layerx-agentd declares no such target (gotcha 2862). Anything that runs the acceptance contract for this scenario will fail even though the task's verify passes.

Kind: connective. Severity: minor.
