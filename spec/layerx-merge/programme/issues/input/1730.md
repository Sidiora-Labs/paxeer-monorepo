# Issue 1730: [Coherence] The rewritten wallet balance test expects success without --gateway-rpc and expects no verification field, but the CLI requires the flag and adds one

## Defect and impact

wallet_balance_reads_px_get_balances now passes only `--rpc <hosted>` (or the configured endpoint) and asserts the command succeeds and that `data` equals the producer balance document exactly. For a non-emulator transport, the hosted balance path in wallet.rs stops with `gateway_rpc_required` when `--gateway-rpc` is missing. When the flag is present, the path also sets `verification` to `unverified_node_observation`. The test can never pass as written, so the success-path capture the commit claims to prove is unproven.

Kind: connective. Severity: major.
