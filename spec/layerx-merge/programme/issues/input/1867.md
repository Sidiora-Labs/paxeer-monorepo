# Issue 1867: [Coherence] The wallet suite baseline is not retired: all 31 repaired cases are still listed and CI still skips them

## Defect and impact

The commit title and task 22.39.145 both say the wallet suite baseline is retired: do_3 requires deleting every entry whose case now passes, leaving the file empty. The commit never touches tests/ci/data/wallet_vitest_baseline.json, and its own repair record admits the removal was deferred. tools/ci/run_wallet_vitest.py builds a negative --testNamePattern from that file, so the CI wallet job still excludes every case this commit repaired. Those repairs (including the producer changes in human.ts, index.ts, modules/index.ts and web-data.ts) therefore get no regression protection in CI.

Kind: semantic. Severity: major.
