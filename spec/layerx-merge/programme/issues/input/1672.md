# Issue 1672: [Coherence] The new ABI v5 branch in the linter's engine check is a no-op, and it edits a source path outside the task's declared scope

## Defect and impact

engine_violations now sends ABI v5 to WasmEngine::validate_v5 and every other version to validate_versioned. For version 5 both routes already end in the same call, validate_module_metered(engine, wasm, AbiRevision::V5, FuelSchedule::WASMI_0_31_2), so lint behaviour does not change at all. The repair record says this dispatch is what fixes the three tests that failed on attempt 1. That cannot be right, so the record misstates what made the tests pass. Task 22.33.248 also declares touches = programs/sdk/rust/lint/tests only, and lint/src belongs to the sibling task 22.33.247.

Kind: semantic. Severity: minor.
