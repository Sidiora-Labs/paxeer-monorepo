# Issue 1838: [Coherence] Existing Go build-tag and launchpad workflow tests still assert the old ubuntu-latest runner on jobs this commit re-routed

## Defect and impact

The commit changes runs-on for paxeer-go-test.yml tagged-tests, autobahn-integration and hpx-registry, and for launchpad-test.yml launchpad-test, from `ubuntu-latest` to the routed expression. Two existing test modules still require the literal `ubuntu-latest` on those same jobs and were not updated, so they now fail. The task's verify_cmd only runs the new routing tests, the live-input test and two tools/ci tests, so these failures were never exercised.

Kind: connective. Severity: major.
