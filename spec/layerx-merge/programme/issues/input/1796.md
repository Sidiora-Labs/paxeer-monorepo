# Issue 1796: [Coherence] The attestor job still cannot link the policy tests because the programs sandbox archive that the cgo directives require is never built

## Defect and impact

The testkernel package used by the internal/policy tests links -llayerx_programs_sandbox from programs/target/release as well as -llayerx from build/. The new workflow step builds only build/liblayerx.a, and no step in the job builds the release sandbox archive (the Makefile target $(PROGRAMS_RELEASE_RUNTIME_LIB) / programs-release-build). So `go test ./...` still fails to link the internal/policy test binary, this time with 'cannot find -llayerx_programs_sandbox', and the wallet-go-test check stays red. The task's narrow verify command runs only ./internal/policy/evm, which does not import testkernel, so the gate passes without covering this.

Kind: connective. Severity: major.
