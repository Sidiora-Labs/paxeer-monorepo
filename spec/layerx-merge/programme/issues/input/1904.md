# Issue 1904: [Coherence] The disposition of finding 22.33.917.1 says it is resolved, but main no longer binds the reward migration approval, so the production registry is still refused

## Defect and impact

d22-30.kvx marks 22.33.917.1 resolved. Its evidence says registry.json binds pnl-reward-approval.json and that repair_m917_test.go validates the production registry. Commit 3924248dd2 (22.33.917) did set the approval digests and reader fields on migration 180001. The later commit 288ea8df07 (22.33.815) set all of them back to null, and that is the state on main at both the cited revision and HEAD. LoadRewardRegistry therefore rejects the production registry, which is exactly the 'unapproved migration registry' the finding describes. The finding is closed even though the defect is still live, and no task in spec.kvx records the gap.

Kind: semantic. Severity: major.
