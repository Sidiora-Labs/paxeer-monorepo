# Issue 1813: [Coherence] RELEASE.md now describes a 7.0.0 release identity check that the workflow does not perform, and drops the warning that the check is tied to V6120Upgrade

## Defect and impact

The release document now says the Release Check refuses 'an upgrade name that is not a registered node plan' and must accept MergeUpgrade (v7.0). It also removes the accurate sentence that the identity check is tied to node/upgrades_v6120.go. The workflow still greps for 'const V6120Upgrade = "$upgrade"' only, and version.json still holds v6.12.0. Following the document, a v7.0.0 / v7.0 pull request would be refused by the check, and the document no longer explains why.

Kind: semantic. Severity: minor.
