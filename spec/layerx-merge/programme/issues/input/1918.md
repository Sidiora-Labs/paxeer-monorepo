# Issue 1918: [Coherence] Attempt 2 is told to restore two api baseline entries that main does not carry, because their owner 22.39.154 already retired them

## Defect and impact

do_6, decision 3050 and gotcha 3746 say attempt 1 removed TestDevelopmentTransactionStatusFromChainRPC and TestRepair_27_log_free_receipts outside its scope, and tell attempt 2 to restore them "exactly as main carries them". Main does not carry them. Done task 22.39.154 removed both in a41ce5ffb6, and that commit is an ancestor of the attempt-1 base b1fd5106ceae. Both the base and HEAD have 259 baseline entries, and 259 − 115 = 144, which is the count the gotcha reports. Following do_6 would add skips back for two tests that now pass, would break the verify_cmd of the done task 22.39.154, and blames attempt 1 for a removal it did not make.

Kind: connective. Severity: major.
