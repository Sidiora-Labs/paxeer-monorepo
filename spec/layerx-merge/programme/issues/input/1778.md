# Issue 1778: [Coherence] The required F11 component can never appear in the snapshot, because the indexer emits only families F01 through F10

## Defect and impact

The boot gate requires `components.F11 == "available"`. The snapshot producer builds `components` from a fixed array of ten families, F01 to F10, so it never emits an F11 key. Even with the endpoint corrected, require_f11 always returns F11Unavailable and the profile never boots. The new tests pass only because they feed hand-built `{"F11": "available"}` values into the gate and never call read_availability against the real view shape.

Kind: cross-system. Severity: blocker.

## Expected versus actual

Expected: The snapshot view should report F11 availability, which the program spec says will report eleven families, before the agent profile depends on it. Otherwise the agent should read F11 availability from a source that provides it.

Actual: The indexer view never includes F11, so every real availability read is refused as F11Unavailable.
