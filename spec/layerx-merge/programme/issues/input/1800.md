# Issue 1800: [Coherence] The Rust SDK quickstart still says RpcClient::request_funds calls the retired lx_requestFunds method

## Defect and impact

This commit changes RpcClient::request_funds to call px_requestFunds and updates only the .NET quickstart. The Rust quickstart is the page that documents this exact function, and it still says the function calls lx_requestFunds. It also lists lx_requestFunds among the crate's typed wrappers. HostedFaucet.md says that method is retired, so the page for the changed crate now names a method the function no longer sends.

Kind: connective. Severity: minor.
