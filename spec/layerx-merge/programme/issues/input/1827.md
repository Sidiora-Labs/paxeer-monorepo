# Issue 1827: [P2] Keep workflow pnpm pin discovery independent of source line numbers

## Defect and impact

The pnpm workflow-pin test binds its required cases to absolute source line numbers. Subsequent changes to three workflows shift their install steps without updating that inventory. As a result, importing tests/ci/test_package_manager_pins_agree.py raises AssertionError: Missing recorded workflow pnpm install while evaluating its pytest parameter list. The pin tests and the rest of this module cannot collect, including the verification command recorded for repair 22.39.139.

This is a test/qualification regression, not an observed production failure or a claim that a GitHub Actions run failed.
