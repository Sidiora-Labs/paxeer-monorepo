# Issue 1892: [Coherence] The new qualification finding for task 22.39.117 names the chain read-adapter test as its file and symbol, but the failure it records is in the shared/redis package

## Defect and impact

Finding 22.39.117.4 records three shared/redis cases failing with 'namespace required' because L09_NAMESPACE was unset. Its file and symbol fields instead point at sdk/launchpad/shared/chain::TestPhase2ReadAdapterRealRegisteredPool, which the observed sentence says passed. The fields were copied unchanged from the earlier records of the task. Anyone who looks up findings by file or symbol will be pointed at the wrong package and will not find the redis primitives and snapshot-policy tests the record is about.

Kind: semantic. Severity: minor.
