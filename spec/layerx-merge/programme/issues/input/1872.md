# Issue 1872: [Coherence] The verification of task 22.39.163 runs an agent SDK test target that never reads the restored ca.pem, so the build of the actual ca.pem consumer is never exercised

## Defect and impact

Task 22.39.163 restores services/agent/crates/layerx-sdk/tests/fixtures/repair_22_31_227_fixture/ca.pem, and gotcha 3605 names the reader that breaks without it: tests/support/audit_22_30_99.rs line 2033. The task's verify_cmd and tests list, however, run only the repair_22_33_1564 target for that crate. That target includes ca.der from the separate repair_22_33_1564_fixture directory and never touches ca.pem. The git ls-files check proves the file is tracked, but no step runs a test that loads the restored certificate, so a wrong or truncated restore of ca.pem would still pass.

Kind: semantic. Severity: minor.
