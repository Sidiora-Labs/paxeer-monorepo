# Issue 1747: [Coherence] native_approval_clock_units and native_producer_clock_units run the same nonce-test helper and never touch the approval or producer paths they claim to prove

## Defect and impact

repair_22_33_63.rs must prove each finding along the real path. Both clock-unit cases call native::consent_expiry_round_trip, which lives in native_send_nonces.rs; only the directory label differs. That helper uses the nonce suite's synthetic constants (EXPIRY_MS = 200_000, NOW = 100) and its loopback peer. It never runs JourneyEngine::start_native, the approval decision path or preview_send_v2, which are the code paths of native_journey_approval.rs and native_send_producer.rs. Two distinct findings are therefore marked closed by one identical case that exercises neither of them.

Kind: semantic. Severity: minor.
