# Issue 1710: Receipt vector refresher rejects the second V2 producer case

## Summary

The documented receipt-vector refresh cannot process the current producer corpus. At main revision [79a325ee](https://github.com/Sidiora-Labs/paxeer-monorepo/tree/79a325eeb9c437eeca6fd2dcc1acab2bed28d810), the [refresher](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/79a325eeb9c437eeca6fd2dcc1acab2bed28d810/sdk/platform/conformance/fixtures/refresh_receipt_vectors.py#L166-L188) requires exactly one V2 case, but [21e7fad7](https://github.com/Sidiora-Labs/paxeer-monorepo/commit/21e7fad72320ab6e794dcd4a5d3be762f829acab) adds a second, as reflected by the [Go consumer test](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/79a325eeb9c437eeca6fd2dcc1acab2bed28d810/sdk/platform/go/conformance_vectors_test.go#L157-L176).

## Reproduction and expected behavior

In a disposable checkout of the pinned revision, run the [documented refresh command](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/79a325eeb9c437eeca6fd2dcc1acab2bed28d810/sdk/platform/conformance/README.md#L46-L51). It should preserve both V2 cases and refresh all documented downstream artifacts. Instead, the V2 cardinality guard raises `ValueError: missing or duplicate producer cases for V2`, before V4, V5 and the Go checkpoint are refreshed. The [repair record](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/79a325eeb9c437eeca6fd2dcc1acab2bed28d810/rpc/repair_22_31_491.kvx#L28-L35) independently records this failure as outside that repair's scope.

This finding is based on source inspection and the repair record; the refresh command was not executed in this review. The impact established here is a broken fixture-regeneration workflow, not a deployment impact.

## Acceptance criteria

- Accept and preserve both current V2 cases while retaining meaningful missing/duplicate-case validation.
- The documented command completes all intended downstream outputs, including V4, V5 and the Go checkpoint.
- Add a regression against the current corpus that checks the generated artifacts and repeatability/provenance.
