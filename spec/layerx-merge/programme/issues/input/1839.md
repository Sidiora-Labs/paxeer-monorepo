# Issue 1839: [Coherence] Removing PaymentRpc's hosted_gateway_endpoint keyword and receipt_keys method breaks every existing SDK test that still uses them

## Defect and impact

This commit removes the `hosted_gateway_endpoint` keyword from `PaymentRpc.__init__` and moves `receipt_keys()` onto the new `HostedGatewayRpc`. None of the existing callers were updated. Suites under tests/agent/sdk/python and services/agent/sdk/python/tests still build `PaymentRpc(..., hosted_gateway_endpoint=...)` and call `PaymentRpc(endpoint).receipt_keys()`, so they now fail with TypeError or AttributeError before reaching their assertions. The commit's verify command runs only the conformance case and the new local suite, so its passing run does not show these suites still work.

Kind: connective. Severity: major.
