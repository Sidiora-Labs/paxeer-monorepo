# Issue 1621: [Coherence] The KMS provenance finding names services/platform/crates as the moved producer tree, but no such directory exists

## Defect and impact

The finding kms-source-provenance says SOURCES lists platform/crates when the producer tree has moved to services/platform/crates, and its proposal says to name services/platform/crates. Neither path exists at this revision. The platform workspace keeps its members under services/platform/hosted/*, ramps/* and similar directories. A repair task built from this proposal would add another missing path, and the proposal's own rule that every provenance path must exist would then fail.

Kind: semantic. Severity: minor.
