# Issue 1655: Collateral removal modal caps withdrawals by pre-settlement collateral

## Problem

At [a70876da](https://github.com/Sidiora-Labs/paxeer-monorepo/commit/a70876da3cf802acdabe3fdfaa5f49e39e7f1787), the [collateral removal calculation](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/a70876da3cf802acdabe3fdfaa5f49e39e7f1787/apps/perps/src/widgets/trading/modals/collateralRemoval.ts#L55-L65) caps the displayed maximum by `state.collateral`. [getAccount](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/a70876da3cf802acdabe3fdfaa5f49e39e7f1787/precompiles/perps/views.go#L278-L300) returns that as the stored, pre-settlement collateral. The [withdrawal path](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/a70876da3cf802acdabe3fdfaa5f49e39e7f1787/modules/perps/keeper/account.go#L83-L105) first settles the account, and [credits positive PnL to collateral](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/a70876da3cf802acdabe3fdfaa5f49e39e7f1787/modules/perps/keeper/account.go#L320-L338) before [checking withdrawal limits](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/a70876da3cf802acdabe3fdfaa5f49e39e7f1787/modules/perps/keeper/account.go#L371-L386). The modal change was introduced in [ec2e2a88](https://github.com/Sidiora-Labs/paxeer-monorepo/commit/ec2e2a88).

## Expected versus actual

The modal should allow values supported by the authoritative post-settlement withdrawal constraints. With unsettled profit, withdrawable can exceed stored collateral; the UI instead rejects an otherwise valid amount until settlement updates the stored value. This is a temporary UI restriction, not evidence of a loss of funds or an unsafe withdrawal.

## Validation scenario

Using six-decimal USDL units, one owned active long with size 10 base, cost basis $1,000, mark $125, leverage 10x and stored collateral 250 USDL has $250 unrealized profit and $500 equity. With no deficit, funding owed, other positions or orders, a live price and sufficient module liquidity, the [withdrawable formula](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/a70876da3cf802acdabe3fdfaa5f49e39e7f1787/modules/perps/keeper/account.go#L211-L257) gives 375 USDL. The modal caps at 250, while the keeper settles collateral to 500 before checking a 300 USDL withdrawal. Confirm this scenario in an integration test, including margin and tier limits; compare the modal maximum to the keeper outcome.

## Acceptance criteria

- Derive the removal maximum from limits compatible with the keeper's post-settlement checks, including unrealized PnL and funding; continue to prevent amounts exceeding actual risk limits.
- Add coverage for unsettled positive and negative PnL, funding, and exact boundary values, comparing the UI calculation with the keeper.
- Keep the result correct after settlement and account refresh.
