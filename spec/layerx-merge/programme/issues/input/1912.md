# Issue 1912: [Coherence] The new alignment task 22.39.212 leaves out the bridge READMEs, which still describe the placeholder five-attestor, threshold-3 set and the repeated-byte manifest

## Defect and impact

Decision 3042 says every assertion of the placeholder manifest is retired, and task 22.39.212 is the task that aligns the bridge with the governed single-signer manifest. But its touches and do steps only cover the nine config.json files, the audit repair tests, the repair records, the operator runbook and the gap-markers test. Do_1 also limits the edit to the attestors and threshold fields of config.json. contracts/bridge/README.md is not in its touches, and the per-chain READMEs are never named. All of these still say there are five placeholder attestors at threshold 3, and the top-level README says attestors.json holds the 0x1111…0x5555 addresses. Once the task lands, the operator documentation will contradict both the committed manifest and the committed chain configurations.

Kind: connective. Severity: minor.
