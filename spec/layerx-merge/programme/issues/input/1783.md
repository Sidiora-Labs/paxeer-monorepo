# Issue 1783: [Coherence] The interface registry still lists the three deleted issue templates as stable file-format interfaces

## Defect and impact

The commit deletes bug_report.md, enahancement.yml and general_issue.md from .github/ISSUE_TEMPLATE. The specification's interface registry and the generated operations contract still record each one as a stable file_format interface with a signature anchored at line 1 of the deleted file. Anything that resolves interface paths or signatures against the tree will now find three stable interfaces with no backing file.

Kind: connective. Severity: minor.
