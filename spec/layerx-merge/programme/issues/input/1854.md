# Issue 1854: [Coherence] The Go qualification test for the C# behaviour tests still requires LayerX.Sdk.Tests.csproj to target net8.0, so it now fails

## Defect and impact

repairM1368Case in sdk/platform/dotnet/repair_m1368_test.go reads tests/LayerX.Sdk.Tests/LayerX.Sdk.Tests.csproj and calls t.Fatalf unless TargetFramework is exactly "net8.0". Every TestRepairM_1368_* case that goes through this helper now fails with "C# behavior tests must reference the production SDK" when `go test ./sdk/platform/dotnet/` runs, even though the project wiring is correct.
