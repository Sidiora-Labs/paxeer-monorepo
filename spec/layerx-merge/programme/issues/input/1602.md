# Issue 1602: [Coherence] The rewritten web program path test is compiled but never run, so its new result-code and balance assertions are unverified

## Defect and impact

The repair rewrites tests/test_web_program_path.c. Two expected results change from LXP_ERR_PROGRAM_REFUSED to LXP_OK, the fee account is now expected to hold 2*PATH_FEE, and the event record is decoded by hand. The repair record says the test 'inspects real program request-event bytes and retains payment, account-creation and event-digest checks'. The only gate that touches it, test_state_withdraw_web_retired, just runs make on build/tests/test_web_program_path and checks that the build exits 0. No Makefile target, CI workflow or test ever executes the binary, so none of the changed assertions run, and the declared verify command passes whatever the program does at runtime.

Kind: semantic. Severity: major.
