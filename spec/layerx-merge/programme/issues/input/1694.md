# Issue 1694: [Coherence] The task record's qualification entry names a build command that is not the task's declared build_cmd

## Defect and impact

The record says the build failed under an npm install of apps/launchpad/web and files a wiring request to switch the gate to pnpm. The spec's build_cmd for 22.33.970 is already a frozen-lockfile pnpm install of apps/launchpad. So the recorded failure and the wiring request describe a command the task does not declare, and the record misstates how the task was qualified.

Kind: semantic. Severity: minor.
