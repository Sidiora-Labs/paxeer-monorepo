# Issue 1805: [Coherence] Removing the two reconcile paragraphs leaves the interface rows for usePerpsMarkets and useSpotTokenState stale with nothing in the spec still tracking the fix

## Defect and impact

The deleted paragraphs in contracts/perps-client.md were the only open record that interfaces.kvx rows 3.ts-perps-hooks-useperpsmarkets-j27 and 3.ts-perps-hooks-usespottokenstate-j27 still disagree with the code. Both rows are marked status "served" with "reconcile 2026-11-02" notes, but the signatures they carry are not the shipped ones. Tasks 22.33.711 and 22.33.712, which proposed the reconciliation, are marked done, and no pending task targets these rows. After this commit the registry gives the wrong shape for both hooks, and nothing in the repository says it needs correcting.

Kind: connective. Severity: major.
