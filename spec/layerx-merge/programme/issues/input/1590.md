# Issue 1590: [Coherence] Audit finding 12 and doc.13 say contracts/services.md is missing, but the launchpad-api and launchpad-metadata contract sections exist under the spec's contracts directory

## Defect and impact

The record says the registry contract for the launchpad API and metadata services does not exist. On that basis it files a domain-4 doc-drift finding (12) and gives the page the status "missing" (doc.13). Registry contract paths are relative to spec/layerx-merge/, and spec/layerx-merge/contracts/services.md exists with both `### launchpad-api` and `### launchpad-metadata` sections. Because findings in this programme become repair tasks and drive the docs rewrite, this false finding would lead to a pointless repair, or to a duplicate services.md being created at the repository root.

Kind: semantic. Severity: major.
