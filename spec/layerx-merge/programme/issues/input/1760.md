# Issue 1760: [Coherence] The wallet issue and pull request templates still link to apps/wallet/CHANGELOG.md, which this move deleted

## Defect and impact

The commit moves apps/wallet/CHANGELOG.md to docs/wallet/app/CHANGELOG.md. It also rewrites the moved changelog's own links so they point back at the four wallet templates. The templates themselves were not updated, so seven changelog links in them now point at a file that no longer exists, including the #network-context anchors that contributors are told to read before filing network issues. The task's reference test does not catch this. It only greps for the apps/wallet/docs and services/wallet/docs strings, and it checks links only in the two READMEs.

Kind: connective. Severity: minor.
