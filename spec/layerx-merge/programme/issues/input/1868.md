# Issue 1868: [Coherence] The launchpad/perps logo row is dropped as 'different artworks', but the two logos are the same artwork and drifted apart only when task 22.39.70 shrank one copy

## Defect and impact

The repair record says the launchpad and perps logos are different artworks and that the rename commit 637c9c63 changed them. Git history shows otherwise. Both files held the same blob (8214cb3a) until bbfdff2207 (task 22.39.70, 'Shrink the web assets that ship to every visitor') rewrote only apps/launchpad/web/public/icons/logo.svg, turning the embedded 1566px PNG into a compact 42x42 SVG. Removing the inventory row silences the one check that caught this. Perps still serves the unshrunk 1.6 MB logo at /assets/logo.svg, and future edits to either copy are no longer checked.

Kind: semantic. Severity: major.
