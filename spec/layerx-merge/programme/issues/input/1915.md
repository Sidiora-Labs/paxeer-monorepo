# Issue 1915: [Coherence] Adding two golden rows breaks the existing bring-up golden tests, which require exactly the five merge-plan cases

## Defect and impact

The commit adds [golden.custody-release] and [golden.anchor-retired] to merge-bringup.kvx, but two existing tests check that the file holds exactly the five ./node merge-plan cases. test_bringup_goldens.py compares the full set of sections and test_bringup_run.py does the same, then also requires every command to be `go test ./node ...`. Both now fail. The new test reads only its own two rows, so its verify_cmd passes, but req.17047 (run_goldens over merge-bringup.kvx returns every case passed) can no longer be checked by its own tests.

Kind: connective. Severity: major.
