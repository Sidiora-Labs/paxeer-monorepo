# Issue 1639: [P2] Classify the UCP checkout receipt fixture in the SDK pipeline inventory

## Defect and impact

Commit [ecdfc235](https://github.com/Sidiora-Labs/paxeer-monorepo/commit/ecdfc235498ace14c0f6af578121a384dd6dc13d) adds `sdk/platform/conformance/fixtures/ucp-checkout-receipt-v1.json`, but the new shipped file has no SDK pipeline classification. The strict SDK drift check and lock-regeneration path both reject undeclared handwritten files under this output root.

Confirmed by source at current main `bc89ac92e6b057c652ed13ec42725107008ccbf9`. This is an inventory/build-gate defect; no receipt-semantic, runtime or deployment impact is claimed.
