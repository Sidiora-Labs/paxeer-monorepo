# Issue 1620: [Coherence] The audit record reports four specification contract pages as missing, but all four exist under spec/layerx-merge/contracts/

## Defect and impact

The registry's contract fields (for example "contracts/explorer-frontend-config.md#cfg-apis") are paths relative to spec/layerx-merge. The record instead looked for them at the repository-root contracts/ directory. As a result it files four medium doc-drift findings (frontend-contract-page-missing, backend-contract-page-missing, launcher-contract-page-missing, verifier-contract-page-missing), marks doc.14 to doc.17 as "missing", and rates interfaces.kvx (doc.18) as "misleading". Each finding proposes creating the page in a domain-14 repair task, so the record will generate repair work that would create duplicate contract pages beside the existing ones. The audit checker cannot catch this because it only validates the record's structure, not whether a claim is true.

Kind: semantic. Severity: major.
