# Issue 1698: [Coherence] The repair record states a verify command that the task's own spec says cannot install this workspace

## Defect and impact

The new repair record gives verify_cmd as an npm install of apps/launchpad/web followed by the node test. The spec task was revised in attempt 2 because npm cannot resolve the workspace dependencies in apps/launchpad. The task's verify_cmd now uses a pnpm frozen-lockfile install. Anyone who reruns the gate from the record gets the install failure the spec already diagnosed, and the record does not match the command the task declares.

Kind: semantic. Severity: minor.
