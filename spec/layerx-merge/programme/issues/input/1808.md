# Issue 1808: [Coherence] The width ruling for 22.38.1 covers only the ai-market crate tests, but the hosted indexer fixes the availability array at ten entries and calls feature_availability

## Defect and impact

22.38.1 widens feature_availability from ten to eleven entries. Decision 2757 and do_6 limit the inventory of old-width literals to a search of the crate tests. The layerx-indexer service depends on the ai-market crate, sets FEATURES = 10, stores availability as [Availability; FEATURES], compares it with feature_availability, and its view renderer takes &[Availability; 10] with ten feature names. Once 22.38.1 lands, the indexer stops compiling and F11 is never shown. The task's build and verify gates build only the ai-market package, so they will not catch this, and no 22.38 task touches the indexer.

Kind: connective. Severity: major.
