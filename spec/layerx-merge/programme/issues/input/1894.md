# Issue 1894: [Coherence] The readiness checklist is ticked early, and its only evidence is a reference to private files outside the repository

## Defect and impact

Decision 3018 says the candidate evidence task (22.39.182) re-runs the gate at the candidate revision before this checklist line is ticked. It also says each tick records the revision, command, exit status and log location. This commit ticks the line itself, in task 22.39.181. The revision and exit status appear only as pointers to `/out/run/gates.jsonl` and `/out/logs/verify-2.log`, which are not in the repository, so a reader of the public release document cannot check the tick.

Kind: cross-system. Severity: minor.
