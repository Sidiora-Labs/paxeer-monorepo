# Issue 1731: [Coherence] The wallet send tests route px_getAccount to /rpc on the --rpc root, but the CLI only sends px_ account reads to --gateway-rpc, which no test passes

## Defect and impact

The wallet_evm_writes fixture now gives one root endpoint through --rpc. It expects px_getAccount on POST /rpc of that same listener and asserts that wallet send reaches a receipt. In run_write, px_ source-account queries go through a `hosted` closure that requires `write.gateway_rpc` and errors with `gateway_rpc_required` otherwise. No test in tests/ except repair_22_33_1494.rs passes --gateway-rpc. The send success test and the mismatched-account refusal test both stop before any px_getAccount request is made.

Kind: connective. Severity: major.
