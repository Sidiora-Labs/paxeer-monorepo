# Issue 1535: [Coherence] The legacy-import lock file is deleted while the floors file and the task's own verify command still read it

## Defect and impact

The commit deletes services/wallet/ceremony/legacy-import/pnpm-lock.yaml and bumps vitest to 4.1.12 in that package's package.json, but writes no new lock file. legacy-import is its own pnpm workspace (packages: ["."]) and is not an importer of services/wallet/pnpm-lock.yaml. The new floors file still points at the deleted lock, so `lockfloor.py` exits 1, and the verify step `pnpm --dir services/wallet/ceremony/legacy-import --ignore-workspace install --frozen-lockfile` cannot pass without a lock file. The task's verification contract therefore fails at this revision.

Kind: connective. Severity: blocker.
