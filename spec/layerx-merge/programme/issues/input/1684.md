# Issue 1684: [Coherence] The qualifier requires a receipt_ref digest that native Agentd never produces, and the recording replaces the producer's value so the test passes anyway

## Defect and impact

recovered_receipt now requires receipt_ref to equal sha256 of the LXP/v1/receipt domain plus the unsigned receipt. Native Agentd's write_submission hashes the full signed bytes with the domain instead, and the committed dispatch vector carries a third value (ac73…). The recording fixture overwrites the producer's receipt_ref with the SDK digest before replay, so the test never checks what the real producer emits. Against a native Agentd, every committed recovery fails with 'recovered receipt digest mismatch'.

Kind: cross-system. Severity: major.

## Expected versus actual

Expected: The qualifier and native Agentd agree on one receipt_ref definition, and the recorded test replays the producer's own receipt_ref value.

Actual: The qualifier demands domain‖unsigned. Native Agentd emits domain‖signed (or plain SHA-256 elsewhere). The fixture hides this by replacing the producer's value with the SDK's.
