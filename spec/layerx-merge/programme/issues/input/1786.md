# Issue 1786: [Coherence] The readiness summary counts 53 workflow files and 46 disabled ones, but the tree and the page's own table have 52

## Defect and impact

The Summary table says there are 53 workflow files under `.github/workflows/*.yml` and splits them into 7 enabled and 46 disabled. At this revision the directory holds 52 `.yml` files. The Workflows table on the same page also has 52 rows: 21 failure, 13 success, 16 with no run and 2 skipped. So the disabled count should be 45, not 46. The summary's status buckets add up to 50 and leave out the two workflows whose runs are always skipped (`paxeer-ecr`, `paxeer-nightly-ecr`), so the page never accounts for them.

Kind: semantic. Severity: minor.
