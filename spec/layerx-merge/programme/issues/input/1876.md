# Issue 1876: Refresh wallet workspace lockfile for added SDK react-dom/jsdom dependencies

## Summary

The wallet workspace lockfile has not followed the SDK's new development dependencies. This blocks three wallet CI jobs before they reach their tests.

Verified on current main `ca33c0c50b4166d7a73afe0a728a9459a3d78610` and PR #658 head `72fbd902a78cd70ddebde8daf4ce4bd726f7cc64`. The affected source blobs are identical. Introduced by [5577807085a205dc03e13c98ad58d876c8d3e1c6](https://github.com/Sidiora-Labs/paxeer-monorepo/commit/5577807085a205dc03e13c98ad58d876c8d3e1c6).

## Expected versus actual

Expected: a frozen install of the declared services/wallet workspace accepts every importer, including sdk/wallet.

Actual: [sdk/wallet/package.json](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/ca33c0c50b4166d7a73afe0a728a9459a3d78610/sdk/wallet/package.json#L59-L65) declares `react-dom: ^19.0.0` and `jsdom: ^26.1.0`. Its [standalone lockfile](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/ca33c0c50b4166d7a73afe0a728a9459a3d78610/sdk/wallet/pnpm-lock.yaml#L26-L46) was updated, but the [workspace importer](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/ca33c0c50b4166d7a73afe0a728a9459a3d78610/services/wallet/pnpm-lock.yaml#L229-L258) omits both. The [workspace membership](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/ca33c0c50b4166d7a73afe0a728a9459a3d78610/services/wallet/pnpm-workspace.yaml#L1-L5) includes that SDK package.

## Reproduction and evidence

1. Use a clean checkout at the affected revision and the repository's declared pnpm version.
2. Run `pnpm --dir services/wallet install --frozen-lockfile`.
3. It refuses the outdated sdk/wallet importer, naming the two added dependencies.

External CI observed exactly this refusal in [Gateway Vitest](https://github.com/Sidiora-Labs/paxeer-monorepo/actions/runs/42456824895/job/128657528087), [Demo Vitest](https://github.com/Sidiora-Labs/paxeer-monorepo/actions/runs/42456824895/job/128657528326), and [Ceremony import Vitest and pytest](https://github.com/Sidiora-Labs/paxeer-monorepo/actions/runs/42456824895/job/128657528378). Those jobs executed synthetic merge `dab7ee0dbecd9005b74d19b238fac1edd831375c`; source inspection separately verifies the mismatch in main and the PR source. No additional install or suite was executed during this review.

The [workflow](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/ca33c0c50b4166d7a73afe0a728a9459a3d78610/.github/workflows/wallet-test.yml#L96-L101) keeps frozen installs. This is not established as an upload-artifact change regression.

## Acceptance criteria

- Regenerate the wallet workspace lockfile with its declared package-manager version so the SDK importer matches its manifest.
- Preserve frozen-lockfile checks and the added development dependencies.
- Verify a clean frozen workspace install and the three affected CI entrypoints; report any subsequent test failures separately.
