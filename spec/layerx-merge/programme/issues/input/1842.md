# Issue 1842: [Coherence] Decision 2881 and do_15 say the wallet send and token transfer examples already carry --gateway-rpc, but they do not, and send also needs it

## Defect and impact

The new gotcha, decision 2881 and task step do_15 all say the wallet send example (around line 233) already carries --gateway-rpc, and do_15 tells the next attempt to fix only the other eight examples by copying it. In the README, the send and transfer examples carry no --gateway-rpc, and the README never mentions the option at all. The CLI's Send write path calls hosted() and refuses without the option. If the next attempt follows do_15 as written, it has no example to copy and leaves send and transfer undocumented, so the README test that runs the wallet send example can still fail.

Kind: cross-system. Severity: major.
