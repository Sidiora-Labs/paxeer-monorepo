# Issue 1797: [Coherence] The middleware conformance service and its tests still build HostedGatewayRpc with the retired /rpc path, which the constructor now refuses

## Defect and impact

HostedGatewayRpc now only accepts an endpoint whose path is "/". The conformance service still sets hostedGatewayUrl to `${settlement.url}/rpc`, so the merchant checkout check now fails with invalid-rpc-endpoint before it resolves the payee identity. The pay6 RPC transcript test also builds the client with the `rpc` suffix and its gateway asserts request.url === "/rpc". The 22.33.1480 test asserts the opposite of the new contract: the pathname is /rpc and a root endpoint is refused.

Kind: connective. Severity: major.
