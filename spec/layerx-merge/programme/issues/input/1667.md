# Issue 1667: [P2] Initialize V6 genesis when recording all vectors

The default recorder path includes V6 without installing its required token runtime.

At a9379026dc479e3a609bcef2b60b6090744e7b3b, [--vector is optional and defaults to empty](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/a9379026dc479e3a609bcef2b60b6090744e7b3b/daemon/committed-fixture/main.go#L87-L99), and [empty selection includes every registered vector](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/a9379026dc479e3a609bcef2b60b6090744e7b3b/daemon/committed-fixture/main.go#L166-L176). However, [V6 genesis setup only runs for an explicit V6 selection](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/a9379026dc479e3a609bcef2b60b6090744e7b3b/daemon/committed-fixture/main.go#L114-L118). V6 is [registered unconditionally](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/a9379026dc479e3a609bcef2b60b6090744e7b3b/daemon/committed-fixture/vector_v6.go#L113-L120).

That setup installs the benchmark ERC20 runtime at the token address before the peers start. [recordV6RPC later mints that token](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/a9379026dc479e3a609bcef2b60b6090744e7b3b/daemon/committed-fixture/vector_v6.go#L345-L352) and executes sponsored binding whose production delegate [requires successful ERC20 repayment with a 32-byte true result](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/a9379026dc479e3a609bcef2b60b6090744e7b3b/contracts/src/BatchCallAndSponsor.sol#L160-L167). Default EVM genesis has [no code entries](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/a9379026dc479e3a609bcef2b60b6090744e7b3b/modules/evm/types/genesis.go#L11-L15); the all-vector V2 setup configures governance/sequencer activation, not this token runtime. Consequently the no-filter command does not supply the prerequisite V6 receives when selected individually.

Expected: recording without --vector initializes the prerequisites for every selected recorder, or rejects unsupported combinations before starting.
Actual: the dispatcher selects V6 but skips its genesis preparation, so V6 cannot complete its intended token-funded sponsored execution on that fresh chain. This does not claim the complete all-vector command passed before this change or identify its first observed runtime error.

Source-derived reproduction, not executed: run committed-fixture record --paxd PATH --out DIRECTORY without --vector, and compare genesis preparation with --vector vector-v6-sponsored-bind. Add a regression covering empty selection and explicit V6 selection before peer startup, plus an integrated all-selected recorder check.
