# Issue 1897: [P2] Demo Vitest cannot collect TSX panel tests with the installed Vite toolchain

## Summary

Demo Vitest fails before collecting the supported-wallet panel tests because JSX remains in the transformed test module.

This occurred in [CI job 128945757632](https://github.com/Sidiora-Labs/paxeer-monorepo/actions/runs/42550815345/job/128945757632), which checked out `88761d5290c4a874293b4ca26b03ad8a790be1f6`. The affected configuration and test files were rechecked at current main `95e12fab1303f5c8ecbb816e91eca0f64bf04420` and their blob identities are unchanged.

The frozen workspace install succeeds. This is a downstream test-toolchain failure, distinct from the installation failure in #1876. It does not establish a deployed wallet defect.

## Expected versus actual

Expected: `pnpm test` in `services/wallet/demo` transforms TSX and executes the two supported-wallet panel tests.

Actual: the run warns, “Both esbuild and oxc options were set. oxc options will be used and esbuild options will be ignored,” naming `{ jsx: 'automatic' }`. It then fails with `RolldownError: Unexpected JSX expression` at a panel JSX expression. The file collects zero tests; the other test file contains one TODO.

- [vitest.config.ts:4–5](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/95e12fab1303f5c8ecbb816e91eca0f64bf04420/services/wallet/demo/vitest.config.ts#L4-L5) configures JSX only through `esbuild: { jsx: 'automatic' }`.
- [tsconfig.json:8](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/95e12fab1303f5c8ecbb816e91eca0f64bf04420/services/wallet/demo/tsconfig.json#L8) sets `jsx: "preserve"`.
- [FundedAccountPanel.test.tsx:23–24](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/95e12fab1303f5c8ecbb816e91eca0f64bf04420/services/wallet/demo/src/components/FundedAccountPanel.test.tsx#L23-L24) renders JSX. A second JSX expression appears at line 50.
- [Executed CI log](https://github.com/Sidiora-Labs/paxeer-monorepo/actions/runs/42550815345/job/128945757632) identifies Vitest 4.1.12, Vite 8.3.5 and Rolldown 1.2.16, warns that the esbuild JSX option is ignored, and then records the collection failure.

## Reproduction

Use Node 24.22.0 and pnpm 10.34.9, following the Demo job:

1. In `services/agent/sdk/typescript`, run `npm ci --workspaces=false --no-audit --no-fund`, then `npm run build --workspaces=false`.
2. In `sdk/wallet`, run `pnpm install --ignore-workspace --frozen-lockfile`.
3. In `services/wallet`, run `pnpm install --frozen-lockfile`.
4. In `services/wallet/demo`, run `pnpm test`.

The cited external job executed this sequence. This review inspected the pinned source and external logs; it did not perform a new local installation or test run.

## Impact and acceptance criteria

The two panel tests provide no regression coverage while collection fails.

- Configure JSX transformation supported by the installed Vite/Vitest toolchain.
- Retain both panel tests and their assertions.
- Verify the Demo job using its declared setup, reporting any later failures separately.
- Add a regression check exercising actual TSX collection rather than only inspecting configuration text.
