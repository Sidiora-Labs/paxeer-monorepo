# Issue 1782: [Coherence] The deleted wallet image is still allow-listed by the gateway and published in both route catalogues

## Defect and impact

The commit deletes apps/wallet/public/Untitled design.svg, but the hosted gateway's UI asset allow-list still names /wallet/Untitled%20design.svg. The source route catalogue and the generated node catalogue still publish GET and HEAD routes for it as a public-read wallet asset. The node embeds the generated catalogue, so discovery now advertises a route whose upstream only returns 404, which conflicts with each route's 'actual-upstream-operation-and-response-contract' health predicate.

Kind: connective. Severity: minor.
