# Issue 1617: [Coherence] The clean verdict for the v2 user socket describes behaviour the file does not have

## Defect and impact

file.130 rates channels/v2/user_socket.ex clean and says its connect assigns the locale. The v2 socket has only one connect clause, and it returns the socket unchanged. Only the legacy BlockScoutWeb.UserSocket assigns the locale. Under the brief, a clean verdict claims the whole file was read and matches its description, so this note misdescribes the socket's connect behaviour.

Kind: semantic. Severity: minor.
