# Issue 1677: [Coherence] The repair record says the restart test verifies timestamps, but no assertion reads them

## Defect and impact

The repair record for 22.33.537 says the restart regression checks exact pending transaction hashes, row counts, timestamps and the fields returned by the consumer stream. The shared helper compares hashes, counts, block-operation rows and the stream's block_number, hash, index and type. It never reads the inserted_at or updated_at values that the migration adds through Helper.add_timestamps. So the record claims one more verified property than the test proves.

Kind: semantic. Severity: minor.
