# Issue 1779: [Coherence] Task 22.31.587's verify cannot pass with the edits its do-steps prescribe for identity.test.sh

## Defect and impact

The verify of 22.31.587 runs tools/release/tests/identity.test.sh. That test checks the upgrade name against the same wanted value as the version, and it refuses a version.json with any key besides version and upgrade. The do-steps set the version to v7.0.0 and the upgrade to v7.0, and change only the wanted version and the upgrade-name check. So the upgrade check still fails (v7.0 is not v7.0.0), and the key check fails because version.json carries hpx_release_identity, which is already failing on main.

Kind: connective. Severity: major.
