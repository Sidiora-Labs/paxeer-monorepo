# Issue 1869: [Coherence] The new workflow test pins the six-name baseline, but neither task that retires those entries is allowed to touch it, so each retirement turns the Python CI job red

## Defect and impact

tests/ci/test_node_build_workflow_scope.py hard-codes all six skipped names. It requires the baseline list to match them exactly and the workflow to contain exactly one -skip with that exact pattern. The file runs in CI through `make test-tests-python`, which collects tests/ci. Tasks 22.39.116 and 22.39.155 delete their entries from the baseline and the workflow, but neither lists this Python file in touches, and neither task's verify command runs it. Whichever lands first leaves the public Python job failing. 22.39.116 also says to drop the whole -skip pattern and leave the baseline empty, which would remove 22.39.155's entries as well, so the two tasks contradict each other.

Kind: connective. Severity: major.
