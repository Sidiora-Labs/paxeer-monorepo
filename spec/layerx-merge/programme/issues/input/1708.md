# Issue 1708: [Coherence] The new agent-middleware resolveGrant test that 22.31.457 attempt 2 requires is never run by the task's verify command

## Defect and impact

The ruling widens 22.31.457 to the agent middleware and asks for resolveGrant on AgentGrantMiddleware plus one test for it in services/platform/middleware/agent/test. The verify command was left as it was. It runs only the two seller tests and then type-checks sdk/integrations/agents, so the new test can be missing or failing and the task still qualifies. The only check on resolveGrant's behaviour (undefined for an unknown grant, the grant the seller's draw path expects) is therefore never run.

Kind: semantic. Severity: minor.
