# Issue 1546: [Coherence] The Go advisory commit deletes the Cargo.lock of the attestor kernel-vector generator

## Defect and impact

The commit deletes services/wallet/attestor/internal/policy/lx/testdata/kernelvectors/Cargo.lock. That is a Rust crate, and no Go floor in tools/deps/floors/go-root.json covers it. The crate generates the pinned kernel_activities.json fixture and has its own no_kernel_codec test, which the spec cites as acceptance evidence. Without the lock file, its path dependencies on the layerx-crypto, layerx-types and layerx-wire crates and their transitive dependencies resolve fresh, so the generated vectors are no longer reproducible.

Kind: connective. Severity: minor.
