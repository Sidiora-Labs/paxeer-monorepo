# Issue 1849: [Coherence] readme_retired_endpoint still expects the retired 'RPC URL must end in /rpc' refusal, and do_16 sends attempt 15 to the wrong line

## Defect and impact

do_16 and gotcha 3580 place the verification-marker assertion at line 397. That assertion is actually at line 383. Lines 390 to 405 of the same test expect a refusal containing 'RPC URL must end in /rpc', which the CLI no longer emits anywhere after the root-endpoint change (decision 2521): the node client now refuses with 'node RPC URL must name the root endpoint'. The README test also asserts that a root URL is rejected, while the README exports that same root URL as RPC_URL. do_16 forbids any change beyond the two named assertions, so this stale refusal stays in place and readme_retired_endpoint still fails after attempt 15.

Kind: cross-system. Severity: major.
