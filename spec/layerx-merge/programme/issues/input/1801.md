# Issue 1801: [Coherence] The SSH test image fixtures in litt/util/testdata are orphaned now that the only code that read them is deleted, and the container scope list still records the Dockerfile as a reviewed fixture

## Defect and impact

The deleted BuildSSHTestImage was the only code that read testdata/ssh-test.Dockerfile and testdata/start.sh. Both files had already lost their live consumer when the helpers were commented out. Removing the commented copy takes away the last record of what these files were for, so they remain as dead fixtures. tools/containers/check.sh and its test still list the Dockerfile as an out-of-scope test fixture, which tells readers some test still builds it.

Kind: connective. Severity: minor.
