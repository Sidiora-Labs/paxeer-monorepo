# Issue 1829: [Coherence] restore_native_preparation now returns a wire-envelope carrier, but the execution-state test in repair_22_33_1520 still sends its output into native settlement, which can only accept the call-bound carrier

## Defect and impact

This commit changes the public restore_native_preparation so it re-encodes the call as an unsigned wire envelope and restores it with restore_canonical. The resulting disclosure has an Activity source, so its actor is the DID bytes. execution_state_uses_receipt_prestate_and_authenticated_account_status was not updated: it still passes this carrier to committed_native_execution_state_with_account_proofs. That function's execution step compares the 20-byte receipt sender with prepared.disclosure.actor, and that comparison cannot match a DID. The `.expect` on the production consumer will therefore fail. The repair_22_31_217 tests avoided the same break by moving the old producer into a test-local native_call_carrier. The task record says repair_22_33_1520 was only built, never run.

Kind: connective. Severity: major.
