# Issue 1532: [Coherence] Lowering the wallet-services fast-uri floor to 3.1.9 lets the advised fast-uri 4.2.1 copy pass the floor check

## Defect and impact

Decision 2372 and do_5 of task 22.24.12 lower the fast-uri floor in tools/deps/floors/wallet-services.json from 4.2.3 to 3.1.9, on the assumption that the 4.x copy in the lock is already 4.2.3. It is not. services/wallet/pnpm-lock.yaml resolves fast-uri 4.2.1 for @fastify/ajv-compiler and fast-json-stringify, and 4.2.1 is below the 4.x patched release (4.2.3) that do_1 names. lockfloor.py checks each copy against one minimum, and 4.2.1 is above 3.1.9, so the check can no longer catch the vulnerable 4.x copy. The task can qualify while that advisory stays open.

Kind: semantic. Severity: major.
