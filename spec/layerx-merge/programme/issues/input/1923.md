# Issue 1923: [Coherence] No per-crate task covers the layerx-agentd example target, so the final whole-workspace task still meets its lints

## Defect and impact

Decision 3053 splits the daemon into its library (22.39.222) and four test-target groups (22.39.226–229). make agent-lint runs clippy with --workspace --all-targets, which also compiles the daemon's example, examples/review_audit_export.rs. None of the five daemon tasks lints that example. Its lints therefore first appear in 22.39.211, whose do_4 limits repairs to lints that only appear when the members are linted together. That scope does not cover these lints, which undercuts the decision's claim that every member target goes green before the final run.

Kind: semantic. Severity: minor.
