# Issue 1615: [Coherence] The audit record reports the Programs contract page as missing, but it exists under spec/layerx-merge/contracts/programs.md with the cited #runtime-crate anchor

## Defect and impact

Finding 022 and doc 013 say that contracts/programs.md is absent and that the runtime interface rows therefore point at an unreadable contract. In interfaces.kvx, contract paths are resolved relative to spec/layerx-merge. That convention holds for every contract family: there is no root-level contracts/clients.md either. spec/layerx-merge/contracts/programs.md exists, and its runtime-crate section lists terminal.rs, replay_record.rs and portable_replay.rs. The proposal to "restore contracts/programs.md or migrate the anchors" would therefore create a repair task for a defect that does not exist, and it risks a duplicate contract page at the repository root.

Kind: semantic. Severity: minor.
