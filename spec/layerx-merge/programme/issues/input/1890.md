# Issue 1890: [Coherence] RELEASE.md still says the rehearsal script only rehearses the v6.12.0 plan, which contradicts the newly closed D6

## Defect and impact

This commit moves D6 into the upgrade plan's implemented-support table. D6 now says tools/release/rehearse-v6120.sh reads the plan from tools/release/version.json, which names v7.0, and requires --plan-info for that plan. RELEASE.md is the operator-facing description of the same script, and it still says the script rehearses the v6.12.0 plan and does not prove a different upgrade plan. The mismatch existed before this commit, but closing D6 makes it live: a release operator who follows RELEASE.md would decide the script cannot rehearse v7.0, while the upgrade plan now cites it as working v7.0 rehearsal support.

Kind: connective. Severity: minor.
