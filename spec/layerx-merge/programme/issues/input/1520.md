# Issue 1520: [Coherence] The explorer-frontend Dockerfile still copies seven of the deleted tool lock files, so the image no longer builds

## Defect and impact

docker/explorer-frontend/Dockerfile copies each tool's package.json and yarn.lock into its deps stage. This commit deletes those lock files. Docker fails a COPY whose source does not exist, so the explorer-frontend image build breaks at its first tool stage. Separately, deploy/scripts/favicon_generator.sh runs `yarn install --frozen-lockfile` in a directory with no lock file, so the favicon tool's versions are resolved fresh and unpinned on every run.

Kind: connective. Severity: blocker.
