# Issue 1716: Reconcile explorer stat-label palette with the 3:1 contrast requirement

## Summary

The explorer design brief requires muted labels to reach at least 3:1 contrast, but the exact light-mode palette and stat-card recipe introduced by [43b67774](https://github.com/Sidiora-Labs/paxeer-monorepo/commit/43b677746c4917a09c964bb2cb70310b2775cfdb) compose a pair slightly below that requirement.

- [Brief requirement and palette](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/0e547c089b1395c8d677b7c7a797a33bd8d6c4a4/spec/layerx-merge/programme/docs/explorer-ui/design-brief.md#L15-L30).
- [Light surface and muted text tokens](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/0e547c089b1395c8d677b7c7a797a33bd8d6c4a4/apps/explorer/toolkit/theme/foundations/colors.ts#L6-L17): `#F7F8FA` and `#8A91A0`.
- [Stat recipe composes those roles](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/0e547c089b1395c8d677b7c7a797a33bd8d6c4a4/apps/explorer/toolkit/theme/recipes/stat.recipe.ts#L99-L119).

## Validation

Calculate the standard sRGB relative-luminance contrast for the two hex colors: **2.97694:1**, below 3:1 before rounding. Expected: the chosen label/surface pair meets the brief's minimum. Actual: the explicitly specified palette and recipe conflict with that minimum. The [current tests](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/0e547c089b1395c8d677b7c7a797a33bd8d6c4a4/apps/explorer/toolkit/theme/repair-22-35-1.spec.ts#L78-L109) pin the colors and composition but do not measure contrast.

This is a static source and arithmetic finding; no browser rendering or test run was performed. The exact colors are themselves specified in the brief, so this needs design-owner reconciliation rather than a token substitution made in isolation.

## Acceptance criteria

- Reconcile the specified light muted-label/surface colors with the stated contrast minimum and update the brief and theme consistently.
- Add a contrast regression using unrounded values for the actual composed roles.
- Check other text/button pairings against their applicable accessibility targets during that reconciliation.
