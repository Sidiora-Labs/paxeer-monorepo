# Issue 1675: [Coherence] When a balance read fails, the top bar stays on "Resolving vault…" and the Deposit and Withdraw buttons are gone

## Defect and impact

`accountResolved` is now true only when both reads are "ready". The old effect set it to true once both reads had settled, whether they succeeded or not. PortfolioTopBar was not updated for the new "error" state. If either read fails, the bar shows "Resolving vault…" until a retry succeeds. The Deposit and Withdraw buttons are hidden, and the overview panel (which also has deposit actions) is replaced by the error boundary. While the RPC is failing, there is no deposit or withdraw action anywhere on the portfolio page.

Kind: connective. Severity: major.

## Expected versus actual

Expected: The top bar should treat a failed read as settled: either keep the deposit and withdraw actions, or show an error state that matches the boundary's retry.

Actual: After any failed read, the top bar says "Resolving vault…" until a retry succeeds, and the page has no deposit or withdraw control.
