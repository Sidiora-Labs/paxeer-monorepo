# Issue 1920: [Coherence] Acceptance 1.964.3 now points at a test that never checks the fresh-store not-found half of its scenario

## Defect and impact

The scenario for acceptance 1.964.3 has two halves. On a fresh store, the four program reads must answer not-found. After a wind-down start, ReadWindDown must return the stored record. The commit maps it to TestReadProgramLifecycleProducers, the same test it gives 1.964.2. That test reads from a store that activities have already populated, and every read in it expects success. So the not-found half has no test behind it. The tests that do cover it sit in the same file, TestReadProgramAccountsOpaqueCopy and TestReadWindDownAndRetirementOpaqueCopy, and the map uses neither.

Kind: semantic. Severity: major.
