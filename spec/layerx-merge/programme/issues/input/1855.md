# Issue 1855: [Coherence] The platform SDK contract still says the .NET project targets net8.0

## Defect and impact

contracts/platform-sdk.md says the .NET project targets net8.0. After this commit LayerX.Sdk.csproj targets net10.0 and the published package needs a .NET 10 consumer, which the release smoke check now creates with --framework net10.0. Integrators who follow the contract would expect the package to work with net8.0, but the commit drops that target.

Kind: connective. Severity: minor.
