# Issue 1536: [Coherence] Bridge, Programs and Custody pages still document the custody credit activity and cite the source files this commit deletes

## Defect and impact

This commit deletes lxp_bridge_credit.c/.h, lxp_bridge_light.c/.h, lxp_ctx_bridge_credit, and the genesis bridge-profile path that wrote the zero custody-issued supply key. The wiki and site pages still describe LXP_BRIDGE_CREDIT as the registered Bridge activity. They also walk through its verify and execute steps and cite the deleted files and line ranges as sources. Readers are pointed at code that no longer exists and at behaviour the kernel no longer has. The generated docs/system pages already have a regeneration task, and the Custody pages have a task that only removes script references. No spec task covers these sections.

Kind: connective. Severity: minor.
