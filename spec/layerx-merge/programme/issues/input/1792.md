# Issue 1792: [Coherence] Rewriting version.json dropped the hpx_release_identity policy block, which the HPX publish path still requires

## Defect and impact

The commit swaps tools/release/version.json for a two-key object and removes the hpx_release_identity block. tools/hpx/release_identity.py reads that block unconditionally. It is called by tools/hpx/publish.sh on the staged copy of the same file, so every HPX publish now fails with a KeyError ('release identity validation failed'). The repair test test_repair_22_33_806 also asserts the block is present, so it now fails too. Task 22.31.587 only asked for the version and upgrade values to change (do_2); it did not ask for the policy block to be removed.

Kind: connective. Severity: major.
