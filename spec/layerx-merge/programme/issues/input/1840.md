# Issue 1840: [Coherence] The new root-path check makes the account-derivation transport-loss test fail when it constructs its client

## Defect and impact

`_BoundedRpc` now requires `(url.path or "/") == "/"` for PaymentRpc. The account-derivation test builds `PaymentRpc("http://localhost:<port>/rpc")` to check that a lost submission reports unknown-outcome and that a lost read reports transport-failure. Construction now raises `ValueError("invalid-rpc-endpoint")` before any subtest runs. As a result, the unknown-outcome and safe-retry mapping in PaymentRpc.send and _bind_rpc is no longer exercised.

Kind: connective. Severity: major.

## Expected versus actual

Expected: The test should build its node client on the root path so the transport-loss mapping is still exercised.

Actual: The test fails with ValueError invalid-rpc-endpoint when it constructs the client, and none of its outcome assertions run.
