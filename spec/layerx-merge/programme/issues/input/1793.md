# Issue 1793: [Coherence] tools/release/tests/workflows.test.sh still expects v6.12.0 and the old V6120Upgrade grep, so the release test suite fails

## Defect and impact

workflows.test.sh loads tools/release/version.json and requires version and upgrade to be v6.12.0. It also requires the release-check step to contain exactly one `grep -qxF 'const V6120Upgrade = ...' node/upgrades_v6120.go` command. This commit changes the identity to v7.0.0 / v7.0 and rewrites that workflow grep into a two-stage pipeline over node/upgrades.go and precompiles/common/precompiles.go. Both checks now fail, and tools/release/tests/run-all.sh still runs workflows.test.sh.

Kind: connective. Severity: major.
