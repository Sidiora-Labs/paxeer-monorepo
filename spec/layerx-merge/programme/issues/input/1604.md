## Defect and impact

Registry contract paths resolve under spec/layerx-merge, and spec/layerx-merge/contracts/evm-rpc.md is present with a `## client-parity` section that lists all three raw-transaction rows. Because the proposal points to a non-existent gap, a repair task built from it would recreate a file that already exists and leave the stale null prose in the real contract unchanged.

Kind: semantic. Severity: minor.
