# Issue 1729: [Coherence] The lifecycle and registry retired-endpoint proofs are aliases of the receipt proof and never run lifecycle or registry commands

## Defect and impact

test_retired_endpoint_program_lifecycle and test_retired_endpoint_program_registry just call root_receipt(), the same body as test_retired_endpoint_program_calls. That body only covers pax_sequencerReceipt, lx_ refusal and the hosted balance read. Neither proof sends a lifecycle or registry request through the root listener or the gateway route that the findings' proposals require. The fixes in program_evm_lifecycle.rs and program_evm_registry.rs only change the path the capture server expects to "/" and add no authentication or lx_ refusal assertions, so these findings are declared closed without a test that checks them.

Kind: semantic. Severity: minor.
