# Issue 1777: [Coherence] The inference profile reads market availability from the node endpoint, but only the hosted gateway serves that route

## Defect and impact

The availability read sends `GET {node_endpoint}/v1/ai/markets/0x{market}/snapshot` with the node bearer token. That route exists only in the hosted gateway, where it is backed by the indexer's projection and authenticated with a gateway API key. The node behind LAYERX_AGENT_NODE_ENDPOINT has no such route, so in inference-market mode the boot step and every one-second supervision check fail. The profile never reaches Healthy, and the boot order in do_2 cannot complete in a real deployment.

Kind: cross-system. Severity: blocker.

## Expected versus actual

Expected: The F11 availability read should go to the service that actually publishes the market snapshot, using that service's credentials, or to a node read that the node really serves.

Actual: The read goes to the node endpoint, which does not serve /v1/ai/markets, so inference boot always fails with 'inference availability read failed' or 'refused'.
