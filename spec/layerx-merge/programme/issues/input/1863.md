# Issue 1863: [Coherence] The routed-runner test still requires runs-on on the three Platform release gate jobs, which are now reusable-workflow calls without one

## Defect and impact

This commit replaces the inline `programs-acceptance`, `agent-sanitizers` and `agent-fuzz-corpus` jobs in platform.yml with `uses:` calls, so those jobs no longer have a `runs-on` key. `tests/ci/test_workflow_runs_on_routed.py` still lists all three in RESTORED_JOBS, and `test_restored_job_keeps_routed_runs_on` reads `jobs[job_name]["runs-on"]` directly. That lookup raises KeyError for each of the three parametrized cases, so the CI test suite goes red. The commit updated several neighbouring tests to resolve callers to their called jobs, but not this one.

Kind: connective. Severity: major.
