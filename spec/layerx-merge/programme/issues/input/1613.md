# Issue 1613: [Coherence] The audit record marks the legacy importer integration test clean although its own note describes a stub that hides the blocking conflict defect

## Defect and impact

The record lists services/wallet/ceremony/legacy-import/test/import.test.ts as clean. Its note says the test uses an in-memory gateway stub that only checks wallet id, in place of the real gateway's unique-conflict behaviour. That stub is exactly why the blocking finding legacy-conflict-success goes undetected: the test's 409 fires only for a duplicate legacy_wallet_id, while the real admin route returns 409 for any unique collision. The repair proposal for that finding names only importer.ts and admin.ts, so the test that should prove the fix has no recorded repair.

Kind: semantic. Severity: minor.
