# Issue 1784: [Coherence] The new Wallet and Continuous integration release-note sections can never collect a pull request because no labeler rule applies area:wallet or area:ci

## Defect and impact

release.yml now groups release notes under area:wallet and area:ci, but labeler.yml defines neither label. Wallet paths (services/wallet, apps/wallet, sdk/wallet) are labelled area:human, which matches the earlier Human category, and .github/** files get no area label at all. Both new sections will stay empty, and CI changes keep landing under Other.

Kind: connective. Severity: minor.

## Expected versus actual

Expected: Every label that release.yml groups on is applied by labeler.yml, for example area:wallet for the wallet paths and area:ci for .github/**.

Actual: labeler.yml never applies area:wallet or area:ci, so the Wallet and Continuous integration sections are always empty.
