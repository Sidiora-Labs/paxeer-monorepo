# Issue 1691: [Coherence] Two tests in this commit assert opposite FeesRouter log origins for direct precompile calls

## Defect and impact

TestRepairM_948_NativeExecutorTransport fails unless a FeesRouter role log originates at the precompile address (the emitAt rule address = calledAt). TestRepairM_948_NativeExecutorNode, replaying the real node, requires the FeesRouter role log to appear at the FeesRouter surface even when the call goes to the precompile, and its own comment says so. Production emission and the emitAt contract therefore disagree on where FeesRouter role logs originate. Both tests pass only because each is checked against a different producer, so an indexer that trusts the transcript's origin rule will mis-attribute real logs.

Kind: cross-system. Severity: major.

## Expected versus actual

Expected: There should be one origin rule for FeesRouter role logs, matching the node's real behaviour, with both tests asserting it.

Actual: The transcript test requires a precompile origin that only the unused emitAt produces, while the real-node test shows production always emits at the FeesRouter surface.
