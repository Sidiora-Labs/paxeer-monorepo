# Issue 1560: [Coherence] Decision 2394 cites the native budgetCreate branch as the source of the ledger budgetCreate disclosure

## Defect and impact

Decision 2394 and do_7 of task 22.9.17 point to call.rs:728-737 as the code that discloses two amounts for every budgetCreate call. Those lines belong to the ConstructMethod::PayBudgetCreateNative arm. The test in question builds the non-native budgetCreate selector, which goes through the PayBudgetCreate arm at lines 758-786. The two arms behave the same, but the reference sends readers to the wrong code.

Kind: connective. Severity: minor.
