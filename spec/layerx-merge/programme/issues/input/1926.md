# Issue 1926: [Coherence] The bridge README and every per-chain README still describe five placeholder attestors at threshold 3, while the repair record marks the README wiring request as fulfilled

## Defect and impact

The 22.31.402 record used to ask for contracts/bridge/README.md to be updated once the governed signer set landed. This commit empties that request list and says the wiring is fulfilled, but the README was not touched. The README still says the configurations carry PLACEHOLDER:attestor-1..5 at threshold 3 and that the manifest holds repeated-byte addresses. The per-chain READMEs still list 5 attestors at threshold 3. An operator following these docs would fill in five signers, and the proposal generator would refuse them against the 1-of-1 manifest.

Kind: connective. Severity: minor.
