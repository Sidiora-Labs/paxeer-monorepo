# Issue 1807: [Coherence] The affects lists of decisions 2757 to 2761 are prose sentences split into one-character entries instead of task ids

## Defect and impact

All five new decisions store affects as arrays of single characters spelling out a sentence such as "22.38.1 and every task that changes feature_availability...". Every earlier decision lists whole ids or paths, for example decision 2756 with ["22.31.587", "22.31.588", "22.31.607"]. Anything that reads affects to link a ruling to its tasks gets entries like "2", "." and " ", so none of the five rulings is attached to 22.38.1, 22.31.600, 22.31.586, 22.99.77, 22.31.611, 22.38.16 or 22.38.17.

Kind: semantic. Severity: major.

## Expected versus actual

Expected: Each affects list holds task ids, e.g. ["22.38.1"] for 2757, ["22.31.600"] for 2758, ["22.31.586", "22.99.77"] for 2759, ["22.31.611"] for 2760 and ["22.38.16", "22.38.17"] for 2761.

Actual: Each affects list is the characters of an English sentence, about 40 to 90 one-character strings per decision.
