# Issue 1776: [Coherence] The existing 0x0907 ABI freeze test still expects four methods and one event, so it fails now that the ABI has bindPeer, peerBinding and PeerAttestationBound

## Defect and impact

This commit adds two functions and one event to the tee attestor ABI. TestABISelectorsGasAndEvent in teeattestor_test.go was not updated and still requires exactly four methods and exactly one event. The package test suite, including the verify command for this task, fails on the length assertions. The ABI freeze no longer describes the surface being served.

Kind: connective. Severity: major.
