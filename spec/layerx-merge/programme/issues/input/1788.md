# Issue 1788: [Coherence] Three pages still say px_ methods are not public node methods, which contradicts the namespace this commit documents

## Defect and impact

The commit rewrites the namespace sentence on dozens of pages to say the node serves `px` at its root and answers from node state. The rpc/server.go registrations confirm this. Three pages the sweep missed still tell readers that `px_*` methods are hosted-only and 'not public node methods'. On two of them the stale sentence names methods the node itself registers (`px_getBalances`, `px_getCapabilities`), so a reader would send those calls to a gateway they don't need.

Kind: connective. Severity: minor.

## Expected versus actual

Expected: Every page that describes the node/gateway boundary should agree with the new wording: the node serves the `px` namespace, and only `px_register` and `px_requestFunds` are hosted operations that the node answers with -32004.

Actual: docs/wiki/Programs.md, docs/site/docs/platform/faucet.md and docs/site/docs/platform/gateway-rpc.md still say px_* methods are not public node methods, which contradicts the edited pages and rpc/server.go.
