# Issue 1763: [Coherence] Decision 2670 counts only literal old-path strings as references, so relative Markdown links to the moved agent matrix stay broken

## Defect and impact

Decision 2670 defines the references a move must follow by a git grep for the old paths. Relative links to services/agent/COMPATIBILITY.md never contain that string, so the grep cannot find them. In the attempt-1 tree that the ruling keeps, three such links still point at the old location and no longer resolve. The verify test only checks links inside the four moved files, so it passes anyway.

Kind: connective. Severity: minor.
