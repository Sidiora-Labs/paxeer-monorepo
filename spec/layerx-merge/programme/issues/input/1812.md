# Issue 1812: [Coherence] The hand-edited activation runbook no longer matches its generator, so the byte-equality runbook test now fails and regeneration would revert the edit

## Defect and impact

spec/layerx-merge/docs/activation-runbook.md is rendered from programme/data/activation-plan.kvx by programme.activation, and test_runbook_matches_render asserts byte equality with that render. This commit rewrote the file by hand: it dropped the 'Generated from' header, added a v7.0-anchor-store-delete row and a Merge stores section, and changed layerxhost to lxphost while adding layerxchains. The plan data and generator were left alone (they still list layerxhost, no layerxchains, handler runAnchorStoreDeleteUpgrade, four known plans). The programme test now fails, and the next regeneration would bring back the stale store list.

Kind: connective. Severity: major.
