# Issue 1624: [Coherence] The site's Public RPC endpoints reference page still lists sixteen node names and calls api-mainnet-beta the unified router URL

## Defect and impact

The commit rewrites docs/readme/PUBLIC-RPC.md, gateway-rpc.md and unified-network.md to say there are fourteen node names plus api-mainnet-beta at the root, with no router and no separate LayerX interface. The published site reference page, which mkdocs lists in the navigation as 'Public RPC endpoints', was not touched. It still lists api15 and api16, says the gateway API opens with the beta, and names the router URL as the unified interface. Readers now see two site pages that contradict each other about the node set and the router.

Kind: connective. Severity: major.
