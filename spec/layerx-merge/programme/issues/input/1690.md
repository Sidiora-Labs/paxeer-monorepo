# Issue 1690: [Coherence] The native executor transcript proves role origins and Initialized refusals through emitAt, which no production path calls

## Defect and impact

The repair claims to close runtime_emission_proof_gap with 'recorded real PrecompileExecutor emitFamily/emitAt output'. But the Roles and Refusals sections of native-execution.json come from a recorder that feeds generated argument values straight into PrecompileExecutor.emitAt. emitAt has no caller outside precompiles/launchpad/events_test.go. Production role logs go through feeLog, nftLog and emitABIEvent instead, and these have no non-pool Initialized guard. So TestRepairM_948_NativeExecutorTransport certifies per-role origins and 'eight non-pool Initialized refusals' for a helper that real execution never reaches, and the audit finding stays open while marked closed.

Kind: semantic. Severity: major.
