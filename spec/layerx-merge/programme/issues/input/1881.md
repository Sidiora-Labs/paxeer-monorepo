# Issue 1881: [P2] Install gateway test dependencies in the wallet SDK CI job

## Summary
The SDK matrix job installs the agent SDK and standalone wallet SDK but not the gateway dependencies used by two wallet test files. Both files fail during collection on missing `jose`, before their assertions can run.

Verified in main `dd4addbf677b3c65e139efa6b4f44c2858fdedbd` and PR #651 source head `d8180853357213c8fb3654805b75407441229be4`: the workflow, runner, affected test files and gateway helper imports are identical. This is a CI prerequisite defect, not evidence of a deployed wallet failure or a regression caused by the setup-kubectl bump.

## Expected versus actual
Expected: the `Vitest (sdk/wallet)` job provisions the dependencies of the test modules it collects and reaches their assertions.

Actual:
- The [matrix setup](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/dd4addbf677b3c65e139efa6b4f44c2858fdedbd/.github/workflows/wallet-test.yml#L40-L56) installs agent SDK dependencies/build and `sdk/wallet` with `--ignore-workspace`. No gateway dependency installation runs in this job.
- [agent.test.ts](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/dd4addbf677b3c65e139efa6b4f44c2858fdedbd/sdk/wallet/test/agent.test.ts#L25-L32) imports the gateway identity helper at module scope; [identity.ts](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/dd4addbf677b3c65e139efa6b4f44c2858fdedbd/services/wallet/gateway/test/support/identity.ts#L1-L3) imports `jose`.
- [evm-review.test.ts](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/dd4addbf677b3c65e139efa6b4f44c2858fdedbd/sdk/wallet/test/evm-review.test.ts#L15-L21) imports the gateway attestor helper at module scope; [attestors.ts](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/dd4addbf677b3c65e139efa6b4f44c2858fdedbd/services/wallet/gateway/test/e2e/attestors.ts#L13-L16) also imports `jose`.
- `jose` is declared in the [gateway package](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/dd4addbf677b3c65e139efa6b4f44c2858fdedbd/services/wallet/gateway/package.json#L29-L39), not the standalone SDK package.
- The [CI runner](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/dd4addbf677b3c65e139efa6b4f44c2858fdedbd/tools/ci/run_wallet_vitest.py#L43-L56) only supplies a negative `--testNamePattern`. Skipping individual baseline test names does not bypass these top-level module imports.

## Reproduction and observed evidence
On a clean checkout using Node 24.22.0 and pnpm 10.34.9, reproduce the SDK matrix setup:
1. In `services/agent/sdk/typescript`, run `npm ci --workspaces=false --no-audit --no-fund`, then `npm run build --workspaces=false`.
2. In `sdk/wallet`, run `pnpm install --ignore-workspace --frozen-lockfile`.
3. From `sdk/wallet`, run `python3 ../../tools/ci/run_wallet_vitest.py`.

[External CI job 128766526907](https://github.com/Sidiora-Labs/paxeer-monorepo/actions/runs/42492109856/job/128766526907) executed this flow and reported `ERR_MODULE_NOT_FOUND: Cannot find package 'jose'` for both helpers. Summary: 2 failed test files, 23 passed, 5 skipped. That job checked out synthetic merge `728a038c45bbfdb22327798fa50d22cfe7c8a91b`, not the PR source head. Source identity was verified separately. No install, build or tests were newly executed during this review.

## Impact and acceptance
The SDK CI job fails before either affected suite can supply regression coverage.
- Provision the gateway test dependency closure in this job using the repository's declared package/workspace layout, or explicitly restructure the test boundary while retaining coverage.
- Preserve frozen-lockfile checks and do not hide these import failures with broader skips.
- Verify collection and execution from a clean runner with the same setup; report any later fixture/toolchain or assertion failures separately rather than claiming this repair makes the entire suite green.
- Add or update a workflow prerequisite regression check.
