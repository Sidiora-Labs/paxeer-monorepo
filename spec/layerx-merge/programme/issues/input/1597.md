# Issue 1597: [Coherence] The stale pending-policy finding for rpc/AGENTS.md points at the uncle rule instead of the pending rule

## Defect and impact

The finding rpc-agents-pending-policy-stale says the Pending rule is at rpc/AGENTS.md line 7. At the audited revision, line 7 is the 'No Uncle' bullet and the Pending rule is on line 6. Every other finding anchor in the record lands on the line it describes, and all 173 file line counts match. A repair task built from this record would therefore send its owner to the wrong rule, which is the one RPC guidance line that has to stay as written.

Kind: semantic. Severity: minor.
