# Issue 1668: [Coherence] The new test-support package.json declares a jsdom version the test never loads; the test actually uses the wallet demo's jsdom 26.1.0

## Defect and impact

The commit adds apps/perps/src/ui/atoms/test-support/package.json, which pins jsdom 30.1.3 and @types/jsdom 30.0.0. The DOM fixture in the same folder doesn't use that manifest: it builds a require rooted at services/wallet/demo/package.json, so the test runs on the wallet demo's jsdom, locked at 26.1.0. The new manifest isn't listed in apps/perps/pnpm-workspace.yaml and isn't in any lockfile, so nothing installs it. It's a dead manifest that records the wrong dependency, and dependency tooling that scans the tree will pick it up and try to update it.

Kind: connective. Severity: minor.
