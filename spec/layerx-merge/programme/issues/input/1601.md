# Issue 1601: [Coherence] The audit marks Send's main-account-only source check as a high blocking defect, but requirement 2026.1 explicitly requires it

## Defect and impact

send-refuses-opened-account is a blocking high finding saying Send must accept any actor-owned asset account. Acceptance criteria 2026.1 and 2026.2 say Send requires the from field to be the actor's main account and refuses anything else with ErrUnauthorizedDebit. That is exactly what send.go does. The kernel's wider source_matches_actor is a genuine design tension, but the record files the spec-mandated behaviour as a code defect. Its proposal would break a stated acceptance criterion, and the finding counts toward upgrade_ready=false.

Kind: semantic. Severity: major.
