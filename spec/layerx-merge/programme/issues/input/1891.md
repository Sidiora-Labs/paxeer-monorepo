# Issue 1891: [Coherence] The apps/perps workspace lockfile was not refreshed for the new wallet SDK devDependencies, although the repair record says it was

## Defect and impact

sdk/wallet/package.json now declares jsdom ^26.1.0 and react-dom ^19.3.1. apps/perps lists ../../sdk/wallet as a workspace member, but its committed lockfile importer for that member still has neither package. The repair record says apps/perps/pnpm-lock.yaml was refreshed as a side effect, yet that file is not in the commit. As a result, the manifest-versus-lockfile checks fail for apps/perps, and a frozen install of the perps workspace is rejected as outdated.

Kind: connective. Severity: major.
