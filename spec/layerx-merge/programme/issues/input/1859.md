# Issue 1859: [Coherence] Three existing workflow wiring tests still assert the old launchpad and wallet test commands and now fail

## Defect and impact

The commit changes the launchpad Test package step to run from the repository root through `--dir`/`--filter`. It also adds a matrix `include` with a per-row `command` to the wallet Vitest job. The older wiring tests for those same steps were not updated. They still require the old working-directory, the literal `pnpm exec vitest run` and a matrix of exactly `{directory: [...]}`, so all three fail at this revision. test_launchpad_test_workflow.py is even listed in the launchpad workflow's trigger paths.

Kind: connective. Severity: minor.
