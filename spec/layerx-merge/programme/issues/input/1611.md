# Issue 1611: [Coherence] The audit record files a false documentation-drift finding against the layerx-migrate README links, which resolve correctly

## Defect and impact

The record says the README's `../../../../docs/wiki/Migration.md` and `../../../../migrations/README.md` links point into services/docs and services/migrations. They don't. The README sits four directories deep (services/interop/crates/layerx-migrate), so four `..` steps reach the repository root, and both target files exist there. The record also marks the README as stale (doc.014) and gives file.023 an 'issues' verdict. That finding and its proposal would open a repair task that changes correct links into broken ones.

Kind: semantic. Severity: minor.
