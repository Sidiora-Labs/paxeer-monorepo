# Issue 1927: [P2] Replace unsupported git grep pathspec flags in retired-scan repair plan

## Problem

Decision 3062 and task 22.39.214 `do_4` prescribe `git grep --pathspec-from-file=- --pathspec-file-nul` to limit the retired-caller scan. `git grep` does not support these options, so following this repair plan produces exit 129 before any selected file is searched.

The current scanner also uses standard input for `-f -` pattern data. A replacement design must define separate, supported channels for the patterns and selected paths.

## Reproduction

Executed in an isolated scratch repository with Git 2.52.0:

```sh
tmp=$(mktemp -d)
git init -q "$tmp"
printf 'needle\n' > "$tmp/example.txt"
git -C "$tmp" add example.txt
printf 'example.txt\0' |
  git -C "$tmp" grep --pathspec-from-file=- --pathspec-file-nul -n needle
```

Actual: exit 129, `error: unknown option 'pathspec-from-file=-'`.

Control:

```sh
git -C "$tmp" grep -n needle -- example.txt
```

The control exits 0 and prints `example.txt:1:needle`.

Expected: an invocation supported by the qualification environment searches only the selected tracked paths, while retaining the scanner's literal matching and error handling.

## Impact

This blocks implementing the prescribed performance repair as written. It is a defect in the new repair instructions, not evidence that these unsupported flags have already been added to the current scanner or that production behavior regressed. The full repository scan and private attempt tree were not executed.

## Acceptance criteria

- Replace the unsupported flags in the decision and task with a supported, bounded design.
- Keep pattern input and selected-path input unambiguous; preserve literal filenames, including unusual characters, and existing refusal behavior.
- Add a real subprocess regression that exercises selected-path filtering and rejects matches outside the selection. Do not mock away the Git option parsing.
- Run the scanner self-tests and the bounded whole-repository scan in the qualification environment, recording the Git version, exit status and duration.
