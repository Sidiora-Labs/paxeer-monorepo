# Issue 1693: [Coherence] The browser journey now targets the image editor and viewer, but no app route renders either component, so the real journey still cannot reach its assertions

## Defect and impact

The repair points measure.browser.mjs at the labels of MetadataImageEditor ('Coin image') and MetadataViewer ('Coin details' with an img alt 'Coin image' and a 'Trading' panel). Neither CreatorMetadataMedia nor MetadataViewer is imported anywhere outside features/metadata-media and the new test. The only metadata route mounts MetadataV2Editor, a separate 'Coin details' form with no image chooser, no img and no Trading panel. On a deployed creator or viewer URL the journey fails at the region lookup, so the finding ('the real journey cannot reach its declared assertions') is still open. The node test renders the components directly in JSDOM and never runs runMetadataBrowser, so it passes anyway.

Kind: connective. Severity: major.
