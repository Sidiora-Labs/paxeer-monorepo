# Issue 1609: [Coherence] Audit finding 50 claims that the registry-source contract pages are missing, but all of them exist under spec/layerx-merge/contracts

## Defect and impact

Finding 50 in the new audit record says the registry-source configuration and Rust API rows link to contracts/agent-config.md#agentd-env and contracts/agent-rust-api.md#agentd, and that neither page exists. The interfaces registry resolves contract links relative to spec/layerx-merge, and both pages and anchors are there. The row the finding names, 9.fmt-registry-source-config, actually links to contracts/agent-formats.md#registry-source-config, and that anchor also exists. Because this record feeds repair tasks, the false finding would create needless repair work and asks for contract pages to be published that already exist.

Kind: semantic. Severity: minor.
