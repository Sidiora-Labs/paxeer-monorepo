# Issue 1622: [Coherence] The interop check now sends its lx_* account reads to a public node root, which does not serve the LayerX methods

## Defect and impact

The commit changed the default of CHECK_LIVE_INTEROP_RPC from the router's /rpc to the bare node root, but check_interop still reads lx_getBalances, lx_getAccount and lx_getSequence through that URL and sends the hosted gateway key with them. The commit's own help text says those methods are served only by the operator-deployed hosted gateway and not by the public nodes. Before this commit the default pointed at an endpoint that served lx_*; now an unconfigured run fails at the account read instead of exercising settlement. Unlike router, search, registry and indexer, which now require an explicit gateway URL, this check silently defaults to an endpoint that cannot answer it.

Kind: semantic. Severity: major.

## Expected versus actual

Expected: CHECK_LIVE_INTEROP_RPC should name the hosted gateway JSON-RPC endpoint and be required with no node default, as CHECK_LIVE_INDEXER_RPC now is, or default to CHECK_LIVE_ROUTER_URL/rpc.

Actual: It defaults to https://api-mainnet-beta.paxeer.network, a node that does not answer lx_getBalances, lx_getAccount or lx_getSequence.
