# Issue 1794: [Coherence] The inference market guides call the daemon profile and the 0x0907 peer binding unavailable, but both have already landed at this revision

## Defect and impact

README.md says the daemon mode parser accepts only `full` and `human-owner`, so selecting `inference-market` fails. threats.md says the docs do not assert that bindPeer is deployed. Both claims are pinned to base revision 29cba7c7b2. The commits that added Mode::InferenceMarket with its configuration (22.38.14) and bindPeer/peerBinding (22.38.10, status done) are not ancestors of that base, but they are on main before this commit. Operators and clients reading the landed pages are told that working surfaces are missing, and COMPATIBILITY.md repeats that the guides 'identify surfaces still pending at this revision'.

Kind: connective. Severity: minor.

## Expected versus actual

Expected: The availability statements should match the revision where the pages land: the inference-market mode and its configuration exist, and bindPeer/peerBinding exist. Only the surfaces that are still pending should be listed as pending.

Actual: The pages describe the state at an older base revision and tell readers that `LAYERX_AGENT_MODE=inference-market` fails and that bindPeer may not be deployed. Both work on main.
