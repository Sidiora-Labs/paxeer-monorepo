# Issue 1774: [Coherence] The room profile codec in 22.38.1 omits fields that later tasks read from the room profile

## Defect and impact

Task 22.38.1 sets the room profile codec fields as minimum bond, canary ratio, lap size, challenge window, slash fraction, host and protocol shares, and settlement account. Consumer tasks read a room profile maximum token count (22.38.21), queue depth (22.38.22), liveness timeout (22.38.20), acknowledgement window (22.38.17) and canary relative tolerance in basis points (22.38.5), and the codec never produces any of these. The interface row also promises 'maximum tokens', which the producing task does not add.

Kind: connective. Severity: major.
