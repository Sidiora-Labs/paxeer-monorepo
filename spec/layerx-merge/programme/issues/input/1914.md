# Issue 1914: [Coherence] The market sandbox evidence producer still writes raw boundary leaves, but the market leaf verifier now accepts only the record-header envelope

## Defect and impact

VerifiedMarketSandbox::boundary now goes through verify_boundary. That function first splits proof.leaf with PortableBoundary::split_envelope and refuses anything that is not a ReplayRecordHeader envelope. The capture example that produces the market sandbox evidence corpus was not updated. It still writes each `leaf` file straight from execution.boundary_leaves, which are raw leaves, and it still decodes those raw leaves with decode_untrusted. So the real-capture market test (market_sandbox_profile.rs, fed by LAYERX_MARKET_SANDBOX_INPUTS) gets pre/post proofs that the new verifier rejects as Encoding, and no capture produced by this tool can reach a Correct or Incorrect verdict.

Kind: connective. Severity: major.

## Expected versus actual

Expected: The capture example should wrap each leaf with execution.record.header().boundary_envelope(...) when it writes proof leaves, and decode raw leaves with decode_with_header. That keeps the Merkle path over the raw leaf and matches what the market verifier now expects.

Actual: The example writes raw leaves and decodes them with decode_untrusted. The market verifier now refuses raw leaves as Encoding, so the real-capture market case cannot pass.
