# Issue 1811: [Coherence] The nine new decision records store their affects field as a list of single characters instead of a list of affected ids

## Defect and impact

Decisions 2762 to 2770 each set affects to a prose sentence split into one-character strings, for example ["9", ".", "9", "8", ".", "4", " ", ...]. Older decisions use a list of task ids or paths. Any tool that reads affects to find the tasks a ruling touches gets digits, dots and spaces back, so these rulings link to no task. The defect started with decision 2757 and was already in five records. This commit adds nine more, nearly tripling the count to fourteen.

Kind: semantic. Severity: minor.

## Expected versus actual

Expected: Each decision's affects lists the task ids or paths it touches, for example ["9.98.4", "22.31.217"] for 2762 and ["22.38.15", "22.38.16", "22.38.17", "22.38.25"] for 2770, the same way the earlier decisions do.

Actual: Each new affects is one sentence exploded into single-character strings, so no task id can be read from it.
