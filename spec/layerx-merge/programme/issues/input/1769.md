# Issue 1769: [P2] Restore app icons omitted by the Hyperfide directory move

## Defect
The task 22.36.1 relocation moves Hyperfide from `addiqate/hyperfide` to `tools/hyperfide`, but drops app icon files while retaining the packaging and application manifests that require them.

Introduced by [0bb8393](https://github.com/Sidiora-Labs/paxeer-monorepo/commit/0bb8393cc62c80c2dc49a510af8dcd003a640ba8). Rechecked on current main `056f81ae49205218d65b339ed135f94d0c6c50f3` at 2026-11-06 08:39 UTC.

## Source evidence
- Mobile [app.json:8–16](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/056f81ae49205218d65b339ed135f94d0c6c50f3/tools/hyperfide/apps/mobile/app.json#L8-L16) names `assets/icon.png` and `assets/ios-icon-dark.png`; [lines 37–41](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/056f81ae49205218d65b339ed135f94d0c6c50f3/tools/hyperfide/apps/mobile/app.json#L37-L41) also require `android-icon-foreground.png` and `android-icon-background.png`. All four are missing from the [moved assets directory](https://github.com/Sidiora-Labs/paxeer-monorepo/tree/056f81ae49205218d65b339ed135f94d0c6c50f3/tools/hyperfide/apps/mobile/assets).
- The development variant additionally selects missing `icon-dev.png` and `android-icon-foreground-dev.png` in [app.config.js:25–28, 49–56](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/056f81ae49205218d65b339ed135f94d0c6c50f3/tools/hyperfide/apps/mobile/app.config.js#L25-L56). The retained [mobile scripts](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/056f81ae49205218d65b339ed135f94d0c6c50f3/tools/hyperfide/apps/mobile/package.json#L7-L13) still expose Expo prebuild and platform builds.

The build script bundles JavaScript; the packaging wrapper only writes its generated config and invokes electron-builder, without restoring these icons.
- The web [manifest.webmanifest:15–31](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/056f81ae49205218d65b339ed135f94d0c6c50f3/tools/hyperfide/apps/web/public/manifest.webmanifest#L15-L31) retains `/icon-512.png` and `/icon-512-maskable.png`, while both are absent from the [moved public directory](https://github.com/Sidiora-Labs/paxeer-monorepo/tree/056f81ae49205218d65b339ed135f94d0c6c50f3/tools/hyperfide/apps/web/public). Color variants and the 192px defaults remain, so this is not wholesale icon retirement.

The compare records the corresponding old icon paths as removed, rather than moved. This is a file-to-manifest contract break: clean checkouts cannot supply the configured mobile/desktop icon inputs, and the default web manifest advertises missing resources. Exact platform packaging failure behavior has not been executed.

## Repair and validation
Restore these assets under their moved paths, or migrate each retained consumer to a maintained replacement. Cover both production and development mobile variants, stable/nightly desktop channels, and all default web manifest icon URLs. Add a focused check that configured local asset paths exist in a clean checkout, then run the affected nonpublishing package/prebuild checks under the repository workflow.

Static source inspection only: no package installation, build, tests, browser or deployed endpoint checks were run. No release or deployed outage is claimed.
