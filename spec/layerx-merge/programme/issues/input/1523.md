# Issue 1523: [Coherence] Raising sdk/wallet's vitest specifier without updating the services/wallet workspace lock breaks every frozen install of the wallet workspace

## Defect and impact

sdk/wallet is a member of the services/wallet pnpm workspace, and that workspace's pnpm-lock.yaml records the sdk/wallet importer with vitest specifier ^3.2.7. The commit changes sdk/wallet/package.json to ^4.1.11 but never touches services/wallet/pnpm-lock.yaml. pnpm install --frozen-lockfile fails when an importer's specifier does not match the lock, so both the platform CI install step and the wallet-pwa image build will fail.

Kind: connective. Severity: blocker.

## Expected versus actual

Expected: services/wallet/pnpm-lock.yaml should be regenerated with the workspace's own pnpm so that the ../../sdk/wallet importer records vitest ^4.1.11 and resolves 4.1.11 or later.

Actual: The workspace lock still pins the sdk/wallet importer to vitest ^3.2.7 / 3.2.7, so frozen installs in CI and in the wallet-pwa Docker build fail with a specifier mismatch.
