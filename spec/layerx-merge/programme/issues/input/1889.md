# Issue 1889: [Coherence] Task 22.39.183 leaves three arbiter callers outside its touches that decode raw runtime boundary leaves with decode_untrusted, so decision 3029's 'no consumer calls decode_untrusted on a raw leaf' cannot be met

## Defect and impact

Decision 3029 and task 22.39.183 say every arbiter consumer must decode a raw boundary leaf through its record header. The task's touches and consumer list only cover step.rs, market.rs, bisect.rs and proof_arbiter_crate.rs. tests/terminal_trap.rs, tests/market_sandbox_profile.rs and examples/market_sandbox_capture.rs also pass the raw leaves from MarketSandboxExecution.boundary_leaves to PortableBoundary::decode_untrusted, which since 22.31.577 only accepts the v2 envelope. terminal_trap needs no external corpus, so it fails with Encoding on main today, and the path policy ('A task touches only the paths it declares') stops 22.39.183 from fixing it. Its verify_cmd also skips terminal_trap, so the gap won't show up when the task qualifies.

Kind: connective. Severity: major.
