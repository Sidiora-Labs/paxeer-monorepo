# Issue 1513: [P2] Invalidate native archives when their source membership shrinks

## Expected versus actual

Deleting a retired C source should remove its object and defined symbols from the next incremental native archive. The source-deletion-only [84502fe](https://github.com/Sidiora-Labs/paxeer-monorepo/commit/84502fe9152dcf794ce55bbef2916dd29ead3803) exposes a missing build dependency: an already up-to-date archive can remain unchanged, including the deleted DA service member.

This is a source-verified incremental-build defect, not an observed clean-build, CI or deployment failure. No builds or tests were executed for this report.

## Producer/consumer evidence

- [Makefile 44–51](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/65a8dd8a6951490532f4cd7be651075c15d7223b/Makefile#L44-L51) discovers current C sources and derives production/testing object lists. Deleting a source removes its object from these lists.
- [Archive rules 180–195](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/65a8dd8a6951490532f4cd7be651075c15d7223b/Makefile#L180-L195) depend only on those remaining objects. Make does not invalidate an existing target merely because its prerequisite list shrank. With all remaining objects older than the archive, the recipe is skipped.
- The recipe **already removes the old archive before ar**. The problem is that this recipe need not run, not that ar retains members during an executed rebuild.
- [Dependency includes 2607](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/65a8dd8a6951490532f4cd7be651075c15d7223b/Makefile#L2607) also use the current object lists, so the deleted source's old dependency file does not supply an invalidation edge.
- [paxd-native-libs and test-lxphost](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/65a8dd8a6951490532f4cd7be651075c15d7223b/Makefile#L2405-L2413) do not force an archive rebuild.
- The new [TestRetiredDaServiceSymbolsAbsent](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/65a8dd8a6951490532f4cd7be651075c15d7223b/modules/lxphost/retired_da_service_test.go#L7-L22) consumes the actual archive and rejects lxp_da_service.o, lxp_da_serve_chunk and lxp_da_serve_chunk_proof. [The helper](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/65a8dd8a6951490532f4cd7be651075c15d7223b/modules/lxphost/archive_symbols_test.go) reads build/liblayerx.a.
- [D129](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/65a8dd8a6951490532f4cd7be651075c15d7223b/spec/layerx-merge/docs/decisions/D129.md) assumes deleting a source removes archive content immediately; [D137](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/65a8dd8a6951490532f4cd7be651075c15d7223b/spec/layerx-merge/docs/decisions/D137.md) requires retirement proof on compiled products.

Relevant source remains present at current main 65a8dd8a6951490532f4cd7be651075c15d7223b, rechecked immediately before filing.

## Concrete validation steps (not executed)

1. In an isolated checkout of parent 68c2a11c7d0f4aca087f5678e239e109dfcf30f6, successfully run make build/liblayerx.a with repository prerequisites. Retain build outputs and timestamps; ensure the archive is newer than all remaining prerequisites.
2. Advance only to 84502fe9152dcf794ce55bbef2916dd29ead3803 without cleaning. This commit deletes the DA service source and changes two tests, but no remaining C source, header or Makefile.
3. Run make build/liblayerx.a again.
4. Inspect ar t build/liblayerx.a and nm -g --defined-only build/liblayerx.a. The dependency graph predicts no archive rebuild and continued presence of the retired member/symbols.
5. Repeat the retained-output transition for build/liblayerx-testing.a.

A clean build, touching Makefile or an unrelated object rebuild can mask this defect. Do not use those as the incremental regression.

## Impact and acceptance criteria

Local incremental outputs can disagree with the current source membership, causing compiled-product retirement checks to reject an otherwise source-retired component. No surviving runtime caller or deployed consequence is claimed.

- Make source-membership changes an effective input to both production and testing archives.
- A deletion-only transition must regenerate each archive and remove deleted members without make clean.
- Add a regression that retains a previously built archive across source deletion, rather than testing only fresh archives.
- Preserve reuse when neither source membership nor other build inputs change.
