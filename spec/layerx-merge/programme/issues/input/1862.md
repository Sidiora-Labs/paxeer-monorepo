## Defect and impact

This commit moved the key-material exceptions list into a JSON file, tests/ci/data/key_material_fixture_paths.json. The planned baseline text file was never created. The pending follow-up task 22.39.93 still says to empty key_material_baseline.txt and lists only that file in planned_paths. If someone follows that task as written, they will create an empty text file the test never reads and leave all seven JSON entries in place. Once the seven fixtures are moved, the test will then fail, because it expects the misplaced-path set to match a list that still has seven entries.

Kind: connective. Severity: minor.
