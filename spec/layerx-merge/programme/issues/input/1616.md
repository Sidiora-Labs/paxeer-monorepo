# Issue 1616: [Coherence] The audit record marks the explorer websocket contract page accurate, but the record's own high finding shows one of its join rows is wrong

## Defect and impact

doc.17 rates spec/layerx-merge/contracts/explorer-ws.md as accurate. That page says token_instances:<hash> can be joined on both /socket and /socket/v2. The legacy /socket only routes token_instances_old:*, and TokenInstanceChannel.join/3 only matches token_instances:*, so nothing on /socket can reach that join. This is the same defect the record lists as the blocking finding legacy-token-instance-topic. The page also cites v2/user_socket.ex:14 for the token_instances route, which is actually on line 16. Marking the page accurate drops it from the documentation rewrite that the audit records are meant to drive.

Kind: semantic. Severity: minor.
