# Issue 1540: [Coherence] The new absence test names lxp_ledger_apply_bridge_credit, so the kernel-suite retired-uses CI check now fails

## Defect and impact

Task 16.97.1 already removed every kernel test that named lxp_ledger_apply_bridge_credit. It also added a CI check that scans every .c and .h file under tests/ for that identifier and fails on any match. The new file tests/codec/lxp_test_ledger_bridge_credit_absent.c declares the symbol as a weak extern and compares it to NULL, so it names the identifier three times. test_no_bridge_credit_apply_caller now fails at this revision. The spec contradicts itself here: req.1014 ac_1 asks for a weak reference that resolves to null, while req.16965 ac_4 says no kernel test may name the symbol. This commit is what puts the two in conflict.

Kind: connective. Severity: major.
