# Issue 1834: [P3] Make retired-symbol absence tests inspect the linked archive

## Expected versus actual

The newly ported payer-grant cases are documented as absence probes for four retired APIs. They should fail if a forbidden definition reappears in the library.

Instead, all references are weak and the test links `liblayerx.a` normally. A static linker does not extract an archive member merely to satisfy a weak undefined reference. This test has no strong library references, so a restored implementation can remain in the archive while both absence cases still pass.

This is a test false negative. No retired implementation is alleged to be present in the current production archive, and no production vulnerability is claimed.

## Executed positive control

Using the exact pinned test source, `lxp_kernel_case.h`, `lxp_ledger.h` and its transitive headers in a scratch directory:

1. Compile a dummy definition of `lxp_payer_grant_encode` with the declared signature into a separate object and archive it in scratch `liblayerx.a`. `nm` confirms the archive contains a defined `T lxp_payer_grant_encode`.
2. Compile the unchanged test using the Makefile's `liblayerx.a libruntime.a liblayerx.a` ordering.
3. Run the binary with positional case names: `./normal payer_grant_roundtrip` and `./normal payer_grant_mutation_canonical`. **Both exit 0**, despite the forbidden definition in the archive.
4. Relink the same fixture with forced archive inclusion. The unchanged cases fail at lines 22 and 29, respectively, and **both exit 1**.

This is a bounded exact-test mutation check, not a full production build. The runtime archive was empty, the library was the deliberate positive-control fixture, and the unused SQLite link flag was omitted because that library is unavailable locally. Test source and fetched headers were unchanged.

## Impact and acceptance criteria

The aggregate CI can report both cases green without enforcing the new absence contract.

- Check the built archive's defined symbols directly, or use a linkage method that genuinely includes the definitions being tested.
- Keep a positive-control regression that inserts a forbidden definition into an otherwise unreferenced archive member and proves the absence gate fails.
- Retain a passing control when all four definitions are absent.
- Do not restore the retired implementation as a fix.
