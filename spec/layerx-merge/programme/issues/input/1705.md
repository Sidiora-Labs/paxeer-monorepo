# Issue 1705: [Coherence] The task record states that the required baseline run on the unchanged tree was not done, although task 22.33.1172 requires it

## Defect and impact

Task 22.33.1172 requires the verify command to run once on the unchanged tree, with the record noting which tests already failed before the change. The new record says this baseline was not run and gives a gate-ordering reason the task text does not contain. So the record does not show whether the old TestGarbageCollection and TestPurgeLocks fixtures failed or passed before the repair. That is the evidence the test-gap closure is supposed to provide. The test code itself is consistent with the cached-table, GC and file-lock code it exercises.

Kind: semantic. Severity: minor.
