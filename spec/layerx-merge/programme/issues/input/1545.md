# Issue 1545: [Coherence] The advisory raise deletes the go.sum of five nested Go modules, so none of them can build or verify

## Defect and impact

The commit raises the requirements in the go.mod files of tools/paxctl, tools/loadtest, services/wallet/ceremony, services/wallet/attestor and sdk/cosmovisor, and deletes each module's go.sum instead of regenerating it. There is no go.work at the root, so each module resolves on its own and needs its own checksums. Without go.sum, `go build ./...` stops with 'missing go.sum entry' for every external import. The task's own verify_cmd runs `go mod verify && go build ./...` in each of these directories, so it cannot pass at this revision. The floors are written into go.mod, but no build can use them.

Kind: semantic. Severity: blocker.
