# Issue 1557: [Coherence] Task 22.9.37 cannot pass its own build because the SDK compiles precompile-calls.test.ts, which only the dependent task 22.9.10 may edit

## Defect and impact

The SDK's tsconfig compiles every file under test/, so `npm run build` type-checks test/precompile-calls.test.ts. That file still calls perpsOpenPositionCall with the v2 fields (accountId, side, size) and perpsCancelOrderCall with two arguments. 22.9.37 retypes both builders but keeps that file out of its touches and gives it to 22.9.10, which requires 22.9.37. Under strict typing, 22.9.37's build_cmd and verify_cmd fail. 22.9.10 cannot start until 22.9.37 is done, so neither task can qualify.

Kind: connective. Severity: major.
