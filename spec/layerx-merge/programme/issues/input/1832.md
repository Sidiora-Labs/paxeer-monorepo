# Issue 1832: [Coherence] The payer-grant property suite now only checks that symbols are absent, but the spec still says it proves a 2000-grant round-trip and canonical decoding

## Defect and impact

The commit replaces both payer-grant property cases with checks that four codec and verifier symbols resolve to null weak references. Requirement 1041 and acceptances 1.41.1 and 1.41.2 still describe a 2000-grant encode/decode round-trip and a mutation/extension canonicality check, and they name these same test functions. interfaces.kvx still lists lxp_payer_grant_encode, lxp_payer_grant_decode and lxp_verify_payer_grant as stable. Now that core-test-all runs in CI, a passing payer_grant_roundtrip will be read as evidence for a codec property that is no longer tested, and the codec no longer exists. The spec was not updated to retire the requirement or move it to the absence contract.

Kind: cross-system. Severity: major.
