# Issue 1709: Rust fiat replay tests still load the retired receipt corpus

## Problem

[29554815](https://github.com/Sidiora-Labs/paxeer-monorepo/commit/29554815) changes the [fiat journeys](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/603f707f71e5cfe7896841be5d1e735eb7db966f/services/interop/specs/conformance/fiat/sequenced-journeys.json#L24-L34) to `fiat-receipts-v1.json` with new case identifiers. At [603f707f](https://github.com/Sidiora-Labs/paxeer-monorepo/commit/603f707f71e5cfe7896841be5d1e735eb7db966f), the [Rust test consumer](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/603f707f71e5cfe7896841be5d1e735eb7db966f/services/interop/crates/layerx-fiat/tests/sequenced_vectors.rs#L22-L27) still includes `sequencer-receipt-v1.json` and [asserts the old path](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/603f707f71e5cfe7896841be5d1e735eb7db966f/services/interop/crates/layerx-fiat/tests/sequenced_vectors.rs#L303-L330). Its [mutation test](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/603f707f71e5cfe7896841be5d1e735eb7db966f/services/interop/crates/layerx-fiat/tests/sequenced_vectors.rs#L492-L509) also looks up renamed case IDs in the old corpus.

## Expected versus actual

Replay should consume the producer-recorded receipt bytes identified by the journeys. The first replay assertion instead rejects the new path; the mutation test also cannot find the renamed cases. Updating only the path is insufficient because the old helper expects fields no longer present in the new corpus. This is a conformance-test integration defect, not a demonstrated deployed fiat failure.

## Validation

Run `cargo test --locked --manifest-path services/interop/Cargo.toml -p layerx-fiat --test sequenced_vectors`. Compare each journey's declared fixture/case with the loaded corpus and update the consumer to use the new recorded evidence. Construct negative mutation evidence separately rather than relying on removed fixture fields.

## Acceptance criteria

- Replay all three credited rails and submitted/reverted journeys using original new producer bytes and case IDs.
- Preserve mutation rejection and idempotent replay coverage without requiring removed fields.
- The named test target passes.

Static source and JSON inspection only; no repository tests were run.
