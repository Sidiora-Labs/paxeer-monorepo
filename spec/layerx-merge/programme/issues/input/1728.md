# Issue 1728: [Coherence] program_lifecycle_third_shape treats a plain Programs call receipt as proof that a lifecycle operation completed

## Defect and impact

The lifecycle proof sends the V1-layerxprograms-call node receipt to lifecycle_receipt_result_verified and asserts state "completed". That receipt comes from an ordinary program call (selector 0x54bd2b48), not from a deploy, upgrade or wind-down. The file's own header says no lifecycle execution transcript exists yet, but the test still asserts lifecycle completion and is listed as the test that closes the finding. As written, it locks in that any successful Programs-scope receipt counts as lifecycle success. That check is only meaningful in submit_lifecycle_transaction_verified, which also requires the lifecycle event log.

Kind: semantic. Severity: major.
