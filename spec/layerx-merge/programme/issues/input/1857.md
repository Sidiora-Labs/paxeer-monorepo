# Issue 1857: [Coherence] The EVM dependency helper embeds a package-lock.json that the commit never added, so the relayer test package no longer compiles

## Defect and impact

tests/support/evm_dependencies.rs uses include_str!("evm/package-lock.json"), but the only file in tests/support/evm/ at this revision is package.json. include_str! fails at compile time when its file is missing, so the repair_22_31_160 test target cannot build. In that case `cargo test -p layerx-bridge-relayer` stops before it runs any test. The same commit deletes all 20 layerx-bridge-relayer entries from the interop baseline, so the interop workspace job now fails for this whole member rather than tolerating the known failures.

Kind: connective. Severity: blocker.
