# Issue 1529: [Coherence] The floors file leaves out 9 of the 22 required floors, so the floor checker passes for packages that are still below their patched versions

## Defect and impact

Task 22.24.20 says the floors file must record every advised package and floor under its manifest. The new rust-vendored.json enforces only 13 of the 22 floors. The other 9 are moved into a new `findings` array that lockfloor.py never reads, and the Solana manifest's entry is empty. lockfloor.py therefore exits 0 even though Cargo.lock files at this revision still contain versions the spec lists as vulnerable. That verify pass is the only proof the 22.24 advisory family has, so 'closed' is recorded for advisories that are still open. rust-vendored.json is also the only floors file that uses a `findings` key.

Kind: semantic. Severity: major.

## Expected versus actual

Expected: All 22 floors appear under `manifests`, so lockfloor.py fails until every resolved copy meets its floor. A floor that cannot be met should go through the qualification note or a spec decision, and the task should not be marked done while it is unmet.

Actual: Nine floors are left out of the checked section and the Solana manifest has no floors at all, so the verify passes while the advised versions are still in the lock files.
