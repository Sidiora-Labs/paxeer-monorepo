# Issue 1896: [Coherence] The new qualification finding for 22.39.117 attempt 5 names a shared-module chain test as its file and symbol, while the failures it records are three cases in the launchpad API module

## Defect and impact

finding.22.39.117.5 gives file and symbol as sdk/launchpad/shared/chain::TestPhase2ReadAdapterRealRegisteredPool, which was copied unchanged from findings .1 to .4. Its observed text, and gotcha 3733, say that every sdk/launchpad module passed and that the failures were TestDevelopmentAuthorityAttestationCache, TestDevelopmentReviewedInputsMatchRepository and TestDevelopmentReadsMountMarketReads in services/launchpad/api/internal/app. Anyone who triages from the file and symbol keys is sent to a package that passed. The record also uses severity "high", which is not one of the allowed values (blocker, suspect, assumption, note). Earlier records already use "high", but this commit adds another one.

Kind: semantic. Severity: minor.
