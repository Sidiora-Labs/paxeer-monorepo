# Issue 1531: [Coherence] Task 1.2.3 still leaves kernel tests that read the deleted idempotency fields outside its scope, although the commit says every reader is now covered

## Defect and impact

The commit adds lxp_kernel.c and lxp_state_root.c to the touches of task 1.2.3, and its message says every reader of the deleted idempotency state is now in scope. But do_1 deletes the store fields idempotency, idempotency_count and idempotency_retention and the journal fields has_idempotency and staged_idempotency (lxp_state.h:40-42, :57-58), and at least six kernel test files still read those fields. None of them are in touches, and the tasks that own them (1.2.1, 1.2.6, 1.4.4, 1.5.2, 1.23.4) are all done. The verify only builds liblayerx.a and the new absent test, so 1.2.3 can qualify while the rest of the kernel test suite no longer compiles.

Kind: connective. Severity: major.
