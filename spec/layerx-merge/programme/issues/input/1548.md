# Issue 1548: [P2] Port gateway record schemas to the Zod 4 TypeScript signature

The wallet-services dependency update raises the gateway from Zod ^3.23.8 to ^4.6.6, resolved as 4.6.7, but six source calls still use the one-argument Zod 3 record constructor. The exported Zod 4.6.7 TypeScript declaration requires keyType and valueType, so these source calls are incompatible with the gateway's tsc build/typecheck. This is a compile-time API mismatch, NOT a claim that valid requests fail at runtime: Zod 4.6.7 explicitly retains a runtime v3-compat fallback.
