# Issue 1519: [Coherence] The commit deletes all nine yarn.lock files that the new floors file and the task's verify command depend on, so the floor check cannot pass

## Defect and impact

Task 22.24.3 says to raise each tool's lock file with its own package manager and record the floors under that lock file's path. Instead, the commit deletes every yarn.lock under apps/explorer/toolkit/package and apps/explorer/deploy/tools/*, and only adds `resolutions` to package.json. The new tools/deps/floors/explorer-tools.json still names those nine yarn.lock paths. At this revision, running `python3 tools/deps/lockfloor.py tools/deps/floors/explorer-tools.json` exits 1 with nine "manifest does not exist" errors, so the acceptance contract fails at its first command and no floor is enforced.

Kind: semantic. Severity: blocker.
