# Issue 1781: [Coherence] The perf-db license section names a `LICENSE-MIT` file that the repository does not contain

## Defect and impact

The crate is licensed `MIT OR Apache-2.0`. The commit pointed the Apache entry at the root `LICENSE`, which holds the Apache 2.0 text. It left the MIT entry naming a `LICENSE-MIT` file, now as plain text instead of a link. There is no `LICENSE-MIT` at the root or in the crate, so the dual-license notice refers to MIT terms that ship nowhere in the repository.

Kind: connective. Severity: minor.
