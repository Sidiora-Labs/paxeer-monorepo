# Issue 1913: [Coherence] do_2 asks for command-check replacements that name a document or script path, but the validator do_3 keeps rejects any replacement that is not path::TestName

## Defect and impact

For uncovered selectors that are commands (make, cargo, grep, go), do_2 asks for a replacement that names the document or script path the command exercises. do_3 tells the checker to keep the 22.31.438 rules, and under those rules a replacement without '::' is an error, as is a test name that does not appear in the file. Entries written the way do_2 asks will fail the gate. About a dozen selectors are affected, for example 'make -n -s human-check', several 'cargo test/metadata' lines and the 'grep -q ...' line.

Kind: semantic. Severity: minor.
