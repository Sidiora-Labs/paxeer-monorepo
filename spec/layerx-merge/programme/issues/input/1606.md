# Issue 1606: [Coherence] The audit record declares the hosted and CLI platform contracts missing although both exist at the path the interface registry uses

## Defect and impact

The record files a finding, plus two [doc.*] entries with status "missing", claiming contracts/platform-hosted.md and contracts/platform-cli.md do not exist. Registry contract anchors are relative to spec/layerx-merge, and both pages exist there. They carry the exact anchors the registry cites, including ai-artifacts-config-keys with the revocation_mark and retention_mark rows. The record therefore opens a false documentation gap for domain 8. It also misses the chance to check the real contract text against the code, for example the stable /v1/activities and /v1/settle emulator rows that platform-cli.md still lists.

Kind: semantic. Severity: major.
