# Issue 1843: [Coherence] Routing explorer-backend-test and dropping its exclusion row breaks the hosted-job test that task 22.39.147 just landed

## Defect and impact

This commit moves explorer-backend-test to the routed runs-on expression and deletes its `docker-command ubuntu-24.04` row from the EXCLUDED table in runner-routing-check.sh. tests/ci/test_workflow_runs_on_routed.py still lists that job in HOSTED_JOBS. Its test requires the job's runs-on to be the literal `ubuntu-24.04` and requires the exclusion row to be present. Both assertions now fail, so 22.39.147's verify_cmd no longer passes on main.

Kind: connective. Severity: major.
