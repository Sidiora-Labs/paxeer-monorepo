# Issue 1758: [P2] Migrate retained capability-install replies when changing the rung encoding

## Summary

The rung repair in 2c7ff104282ab5e1e67afeb2576086a482d8a366 updates newly built capability-install replies, but it does not update completed replies already retained under `human-capability-action-v1:`. Retrying the same action after upgrading/reopening the store returns those old bytes before the new conversion runs. A retained COMMITTED verification label of 6 is therefore still rejected by Human's rung decoder.

This is a source-proven compatibility/recovery failure. No runtime test, live transaction, or deployed impact is claimed.
