# Issue 1844: [Coherence] The new container-runtime step breaks the explorer test that allows exactly one run step in explorer-backend-test

## Defect and impact

The commit adds a second `run:` step to explorer-backend-test, "Install and verify the container runtime". tests/ci/test_explorer_test_step.py collects every step that has a `run` key and asserts there is exactly one, the mix-in-builder umbrella test. That assertion now fails. The commit's verification only ran tools/ci, so it did not catch this.

Kind: connective. Severity: major.
