# Issue 1787: [Coherence] The register row in the docs-site CLI command table still omits the required --gateway-endpoint flag, though the faucet row next to it was updated

## Defect and impact

The commit adds the required `--service-endpoint` to the docs-site `faucet` row. It leaves the `register` row reading only "Optional `--key`, otherwise default". `RegisterArgs` declares `gateway_endpoint: String` with no default, so clap requires `--gateway-endpoint`. A reader who follows the table will run `layerx register` without it and get an argument error. The same page's prose, the wiki table and docs/system/cli.md all name the flag as required.

Kind: connective. Severity: minor.

## Expected versus actual

Expected: The docs-site register row should state "Required `--gateway-endpoint`; optional `--key`, otherwise default", matching the faucet row and the wiki.

Actual: The register row presents `--key` as the only option, so running `layerx register` as documented fails because `--gateway-endpoint` is missing.
