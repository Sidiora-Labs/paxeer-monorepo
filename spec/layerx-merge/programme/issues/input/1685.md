# Issue 1685: [Coherence] The endpoint fixture now answers only the root path while scripts/wallet/check-live.sh still posts to $base/rpc, so the endpoint probe regressions fail at this revision

## Defect and impact

The commit changed the shared endpoint fixture to return 404 for any path other than "/" and made run_endpoint_account_probe assert four requests to "/". The production checker was not changed and still sends every JSON-RPC call to "$base/rpc". Every run of test_endpoint_account_probe_passes_a_resolved_account (8 cases) and test_endpoint_account_probe_fails_a_read_refusal (3 cases) therefore gets a 404 HTML body on all four checks and then fails the path assertion. The repair record says finding 013's production routing belongs to task 22.34.6, which is still pending, and that this task makes "no script changes". That means the test side was switched to the root path before its producer was.

Kind: cross-system. Severity: major.
