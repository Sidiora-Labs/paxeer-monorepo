# Issue 1803: [Coherence] The existing embedded-wallet test still expects the removed default endpoint and a null result when nothing is configured

## Defect and impact

embedded-wallet.test.ts sets only the publishable key and expects apiUrl to equal the removed default https://connect.paxportwallet.com. It also expects an empty browser environment to return null. After this change both calls throw, so chainIdFromChainObject fails. The new repair test covers the throw, but the old test was never updated.

Kind: connective. Severity: major.
