# Issue 1720: Keep the home chart within its stated calendar-day window

## Summary
[5319611d](https://github.com/Sidiora-Labs/paxeer-monorepo/commit/5319611d653b2ac13055377553f39f93636bfa25) removes null observations during [chart preparation](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/77e6aa67194dac604e249ad0b0bbbfa9d112492f/apps/explorer/ui/home/indicators/utils/chart.ts#L34-L39), before the [consumer takes the last `days` items](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/77e6aa67194dac604e249ad0b0bbbfa9d112492f/apps/explorer/ui/home/indicators/ChainIndicatorsChart.tsx#L25-L31). The [home label](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/77e6aa67194dac604e249ad0b0bbbfa9d112492f/apps/explorer/ui/home/Stats.tsx#L14-L30) describes transaction history in 14 days, but 14 non-null observations can span more than 14 calendar days. The [backend](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/77e6aa67194dac604e249ad0b0bbbfa9d112492f/services/explorer/backend/apps/block_scout_web/lib/block_scout_web/controllers/api/v2/stats_controller.ex#L153-L171) supplies dated daily counts over a configurable range, defaulting to 30 days.

## Validation
Supply daily samples for January 1–30 with January 29 null and render the 14-day chart. Expected: the calendar window January 17–30, retaining the distinction between missing and zero. The source instead filters the null first and selects January 16–28 plus January 30, spanning 15 calendar days. The [tests](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/77e6aa67194dac604e249ad0b0bbbfa9d112492f/apps/explorer/ui/home/repair-22-35-4.spec.tsx#L179-L206) cover null removal and point counts but not the displayed date bounds.

This is source-derived; no browser or test run was performed.

## Acceptance criteria
- Select the stated calendar-day window by date before excluding missing observations, or otherwise ensure displayed dates stay within that window.
- Preserve real zero values and do not fabricate zeroes for missing data.
- Add sparse-history, leading/trailing null and date-boundary regressions.
