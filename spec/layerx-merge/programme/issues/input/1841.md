# Issue 1841: [Coherence] The commit claims it documents the hosted URL option in the CLI README, but the README is unchanged and no example carries --gateway-rpc

## Defect and impact

The commit title says every platform CLI README example that runs a hosted px_ read or account write now shows the explicit hosted URL option. The diff only touches GOTCHA.kvx, qualification.kvx and spec.kvx; tools/platform/cli/README.md is untouched. Every hosted example still names only --rpc and --gateway-credential, so readme_retired_endpoint and readme_operator_contract keep failing with the gateway_rpc_required refusal recorded in finding 22.39.118.13.

Kind: semantic. Severity: major.
