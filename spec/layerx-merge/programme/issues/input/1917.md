# Issue 1917: [Coherence] The new qualification record for attempt 7 of 22.39.117 names an unrelated chain test as its file and symbol instead of the production test cases that failed

## Defect and impact

finding.22.39.117.7 says the failure was three cases in sdk/launchpad/shared/db/production failing on roles and a table left behind by the first pass. Its file and symbol fields still name chain::TestPhase2ReadAdapterRealRegisteredPool, a test in the chain package that played no part in the failure. These two fields were copied from finding.22.39.117.6. Anyone who looks up the record by file or symbol is sent to the wrong package, and the record cannot be matched to the fixture that decision 3048 and do_9 correct.

Kind: connective. Severity: minor.
