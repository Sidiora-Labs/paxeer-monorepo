# Issue 1542: [Coherence] Kept tests still read lxp_state_store.idempotency_count and journal.has_idempotency, which this commit removes, so they no longer compile

## Defect and impact

The commit removes idempotency, idempotency_count and idempotency_retention from lxp_state_store, and has_idempotency from lxp_state_journal. At least eight kept test sources still read these fields. Two are in aggregate targets: tests/state/lxp_test_state_root.c (test-state-root) and tests/test_state_commitment_transition.c (the test aggregate). The others are built by the kernel pattern rule. Every one now fails to compile with -Werror -pedantic. No pending spec task schedules their migration, and task 1.2.3's touches list covers none of them.

Kind: connective. Severity: blocker.
