# Issue 1924: [Coherence] The lint record skips the unchanged-tree Clippy inventory that the task's first step requires, so its lint list is not the baseline the task describes

## Defect and impact

Task 22.39.216 says Clippy must run once on the unchanged merged main tree, and every lint it reports must be recorded by file, line and lint name. The committed record says outright that no baseline ran. Its diagnostics section comes from a later verification at a different revision, after the implementation was complete. Several source repairs (maintenance.rs digit separators, handover.rs try_from, the unwrap_used rewrites) are listed without any compiler diagnostic behind them. The record therefore cannot show that every lint on the base tree was found and repaired, which is what do_1 and do_3 ask for.

Kind: semantic. Severity: minor.
