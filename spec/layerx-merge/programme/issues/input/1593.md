# Issue 1593: [Coherence] The audit record declares the sequencer and consensus-fork contracts missing although both exist and carry the reviewed rows

## Defect and impact

doc.020 and doc.021 mark contracts/sequencer.md and contracts/consensus-fork.md as missing at the reviewed revision. They say source code and acceptance criteria were used in place of the contract text. Both files exist under spec/layerx-merge/contracts/, the directory that the interface rows' relative contract links resolve against, and they existed at the declared revision 6d2c32a65a. sequencer.md's #node-cli section lists the exact layerxctl rows this slice audits. So no contract-versus-implementation comparison was done for the CLI, storage and consensus interfaces, and finding f032 asks follow-up work to 'supply the missing linked sequencer contract' when that contract already exists.

Kind: semantic. Severity: major.
