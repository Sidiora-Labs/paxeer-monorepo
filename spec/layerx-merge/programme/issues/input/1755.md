# Issue 1755: [Coherence] The negative case specified for 22.31.562 is already refused by the existing COMMITTED check, so it never reaches the new label-without-rung refusal

## Defect and impact

Task 22.31.562 do_2 expects a budget-state fixture labelled SEQUENCER_SIGNED (1) to answer Refused, as proof of the new rule that refuses a label with no rung. SEQUENCER_SIGNED does have a rung (Submitted, rank 0). approval_budget_after also already refuses any label other than COMMITTED through budget_state_is_committed before the response is encoded. The test therefore passes on the old check alone and says nothing about the new conversion's refusal path. That refusal can only fire for retired labels 4 and 5, and from_wire_rank already refuses those.

Kind: semantic. Severity: minor.
