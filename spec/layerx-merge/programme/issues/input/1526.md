# Issue 1526: [Coherence] OpenTelemetry core is pinned below the exact version the raised Jaeger propagator requires

## Defect and impact

The manifest forces every @opentelemetry/core copy to 2.8.0. The same commit raises @opentelemetry/propagator-jaeger to 2.9.0, which declares an exact dependency on core 2.9.0. The lock squeezes 2.9.0 and ^2.9.0 requests (and 1.x requests) onto 2.8.0. Telemetry packages built against 2.9.0 now run against an older core than they declare, and the lock records versions that do not satisfy their own ranges.

Kind: semantic. Severity: major.

## Expected versus actual

Expected: Core resolves to a version that is at or above the 2.8.0 floor and also satisfies its dependents: 2.9.0 for propagator-jaeger 2.9.0, with no 1.x consumer forced onto 2.x.

Actual: Every core copy is pinned to 2.8.0, below the exact 2.9.0 that propagator-jaeger declares and outside the 1.x ranges of older instrumentation.
