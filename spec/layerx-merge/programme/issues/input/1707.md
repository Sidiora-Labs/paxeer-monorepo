# Issue 1707: [Coherence] Interface ledger and sequencer contract still record the removed state-test env var reads as stable

## Defect and impact

This commit deletes the `specificDir`, `specificTestName` and `ignoreSkipList` reads and the `VerifyEthereumSpec: os.Getenv(...)` read. VERIFY_ETHEREUM_SPEC and IGNORE_SKIP_LIST are now required to equal `true` rather than acting as switches. The commit also adds STATE_TEST_FORK, STATE_TEST_COUNT and STATE_TEST_ROOT as required inputs. interfaces.kvx and contracts/sequencer.md still list the old signatures, line numbers and opt-in meaning as stable, and the new variables are not registered.

Kind: connective. Severity: minor.
