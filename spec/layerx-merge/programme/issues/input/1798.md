# Issue 1798: [Coherence] Existing wallet SDK and wallet app tests still assert that px_ reads go to the hosted transport or fail without hostedUrl

## Defect and impact

isHosted is now true only for px_register and px_requestFunds, so resolveAccount, getNetwork, getBankBalances and px_ entries in mixed batches all go to the node and no longer require hostedUrl. Several committed tests still assert the old routing. The SDK endpoint test expects a mixed batch to split into two requests. The 22.31.238 test expects default-client reads and a px_getNetwork batch to throw /hostedUrl/. The wallet app test expects the 'hostedUrl required for hosted px_ reads' alert. These tests now fail; the task's narrow verify command never runs them.

Kind: connective. Severity: major.
