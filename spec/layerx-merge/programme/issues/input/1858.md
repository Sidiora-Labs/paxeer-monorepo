# Issue 1858: [Coherence] The rewritten launchpad and sdk/wallet test steps are no longer recognised by the JavaScript suite-runner guard in ci.yml, so 12 packages read as having no runner

## Defect and impact

The guard `tests/ci/test_js_suites_have_runner.py` runs in ci.yml. It decides whether a package's test script has a runner by parsing workflow `pnpm` commands: it understands `--dir`, but not `--filter`, and it only counts `pnpm`/`npm`/`yarn` commands. The new launchpad step `pnpm --dir apps/launchpad --filter ... run test` resolves to the apps/launchpad manifest, takes `--filter` as the script name and skips the step. The sdk/wallet row now runs `python3 ../../tools/ci/run_wallet_vitest.py`, which the guard never looks at. Running the guard's coverage function on this revision reports all nine sdk/launchpad packages, apps/launchpad/web, apps/launchpad/mobile and sdk/wallet as uncovered; at the parent revision only the pre-existing sdk/integrations/express/example gap shows. The result is that test_js_test_scripts_have_runner fails in ci.yml.

Kind: connective. Severity: major.
