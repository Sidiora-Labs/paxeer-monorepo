## Problem

At current revision [b4bbe0b](https://github.com/Sidiora-Labs/paxeer-monorepo/commit/b4bbe0b5a4ba8e3cbaafc5198f1ec7d20dafe66a), [the retained lifecycle test](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/b4bbe0b5a4ba8e3cbaafc5198f1ec7d20dafe66a/tests/agent/sdk/python/test_program_lifecycle.py#L54-L56) calls `verify_lifecycle_recovery` without the required `signed_activity` and `receipt_keys` arguments. See [current signatures](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/b4bbe0b5a4ba8e3cbaafc5198f1ec7d20dafe66a/services/agent/sdk/python/layerx_sdk/programs.py#L196-L215).

No production or deployment impact is inferred from this test mismatch.
