# Issue 1599: [Coherence] Task 5.99.1 traces to an acceptance scenario about sequencer proposer checks, not the programs ABI switch

## Defect and impact

Both the capability and the task for 5.99.1 set reqs = ["5004.1"]. Requirement 5004.1 is the checkSequencerProposer leader-list scenario, so qualifying the ABI switch would be recorded against an unrelated criterion, and no acceptance criterion describes the merge-upgrade ABI behaviour. The new task 9.98.4 also cites req 9998.1, which no acceptance block defines.

Kind: semantic. Severity: minor.
