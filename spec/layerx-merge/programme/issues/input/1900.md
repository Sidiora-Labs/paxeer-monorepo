# Issue 1900: [P2] Provision the disposable Paxeer node required by Gateway Vitest

## Summary

The Gateway Vitest CI job reaches its tests after successful frozen installs, but four real-node tests fail because the workflow provides no disposable Paxeer node RPC endpoint.

[Job 128945757368](https://github.com/Sidiora-Labs/paxeer-monorepo/actions/runs/42550815345/job/128945757368) ran at `88761d5290c4a874293b4ca26b03ad8a790be1f6`. The workflow, setup and affected tests were rechecked at current main `89e829476ec2c99f9e830c5d9338ab933ed1adc5`; the missing prerequisite remains.

## Expected versus actual

Expected: the CI job provisions an isolated disposable Paxeer node with the interfaces required by these integration tests, waits for readiness and supplies its fixture URLs.

Actual: the job installs Anvil but does not start the required Paxeer node or set `HYPERPAXEER_RPC_URL`/`EIP712_NODE_RPC_URL`. Test setup defaults to `http://localhost:0/rpc`. Both EIP-712 cases and both streams cases explicitly reject that placeholder.

## Reproduction

1. Use a clean CI runner with Node 24.22.0, pnpm 10.34.9 and the Go, Anvil and PostgreSQL tools declared by the Gateway job.
2. Follow the job's agent SDK build, isolated wallet SDK frozen install and services/wallet frozen install.
3. Leave the two node fixture URL variables unset, as in the checked-in job.
4. Run `pnpm exec vitest run test/agent-precompiles-eip712.test.ts test/agent-precompiles-streams.test.ts` from `services/wallet/gateway`, or run the existing job's full `pnpm test`.

The full job was executed by GitHub Actions. No fresh local test execution or network endpoint probing was performed during this review.

## Impact and acceptance criteria

These four integration checks cannot validate their intended node interfaces under the declared CI setup. The same job has other failures; this report does not attribute them all to this prerequisite.

- Provision a disposable local test node with the necessary state and interfaces, with a readiness check and cleanup.
- Pass the appropriate fixture URLs to Gateway Vitest.
- Retain the real-node assertions and both suites; do not mask the prerequisite by skipping the tests or pointing them at public production infrastructure.
- Run the focused four cases from a clean runner and separately report remaining Gateway suite failures.

## Duplicate checks and limits

All-state issue and PR searches for the two test filenames, `EIP712_NODE_RPC_URL`, `disposable Paxeer node` and the workflow/URL combination found no matching report. The related closed #1001 concerns a different EVM receipt fixture. Inspected audit/disposition records did not establish a repair owner for this provisioning gap; the oversized active specification could not be exhaustively checked.

This is a CI-fixture defect, with no deployed precompile or wallet failure asserted.
