# Issue 1789: [Coherence] BetaCluster still says the primary container runs `paxd start --home /var/lib/paxeer` on a `/var/lib/paxeer` volume, which contradicts the updated PaxeerBoundary page and the manifest

## Defect and impact

This commit updates PaxeerBoundary.md to say the harness volume is mounted at `/data` and the `paxd` container runs `kernel_runtime.py --home /data/layerx/node`. That matches deployment.yaml. BetaCluster.md was edited in the same commit, but it still says the primary container in deployment.yaml runs `paxd start --home /var/lib/paxeer` and that the StatefulSet's 40Gi data PVC is at `/var/lib/paxeer`. So the two wiki pages now disagree about the same manifest, and an operator following BetaCluster would look for a home directory and command the harness no longer uses.

Kind: connective. Severity: minor.
