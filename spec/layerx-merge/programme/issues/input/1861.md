# Issue 1861: [Coherence] The chainflow SDK docs still give the old Python 3.9 and Go 1.22 minimums after the manifests were raised

## Defect and impact

The Python SDK manifest now requires Python 3.11 and the Go module now declares go 1.25. The SDK READMEs and the agent skill files shipped beside them still state the old minimums. Users on Python 3.9 or 3.10 will follow the docs and then fail the pip resolver, and Go users get a toolchain floor that is out of date.

Kind: connective. Severity: minor.
