# Issue 1910: [Coherence] The new single-signer manifest no longer matches any of the nine committed chain configurations, so every chain is refused against it

## Defect and impact

The manifest now records one attestor with threshold 1. All nine chain configurations still carry five named placeholder slots with threshold 3. AttestorManifest.Check compares the count first, so every chain configuration is now refused as "5 attestors against the 1" the manifest records. Before this commit the manifest and the chains agreed on structure. The repo's own consistency test, test_attestor_manifest_matches_every_committed_chain, compares attestors and threshold exactly and now fails for all nine chains.

Kind: cross-system. Severity: major.
