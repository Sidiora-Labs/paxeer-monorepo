# Issue 1916: [Coherence] Moving the candidate gate task 17.0.9 to the go-cgo profile drops the forge and Node toolchains that its wave-gate reruns need

## Defect and impact

Decision 3046 says 17.0.9 "runs every golden of the programme" and moves it from mixed to go-cgo. That is not what the task does. Its do_1 reruns scripts/gates/wave-0.sh through wave-6.sh and wave-programme.sh, and those call make workspace-build, workspace-test, workspace-lint and workspace-ci. Those targets run forge build and forge test plus the agent, human and platform TypeScript suites. The go-cgo profile only provides Go with cgo, a C compiler, make, Rust and OpenSSL. So the candidate gate's first attempt will fail on missing toolchains, which is the same class of failure this decision was meant to head off.

Kind: semantic. Severity: major.

## Expected versus actual

Expected: 17.0.9 should keep a profile that has every toolchain the wave gates use (a mixed union that includes go-cgo, solidity and node, with the kernel archive prebuild), or the decision should say how forge and the Node suites get satisfied.

Actual: 17.0.9 now carries plain go-cgo, chosen because the decision wrongly describes it as running the goldens. Its make workspace-* and forge steps will fail for lack of toolchains.
