# Issue 1761: [Coherence] The ruled continue keeps an attempt-1 tree in which layerx-agentd can no longer compile, because compat.rs embeds the moved compatibility matrix by relative path

## Defect and impact

The attempt-1 tree that do_3 says 'stands' moves services/agent/COMPATIBILITY.md to docs/agent/COMPATIBILITY.md. It leaves compat.rs embedding the matrix with include_str!("../../../COMPATIBILITY.md"), which now points to a file that does not exist, so the layerx-agentd crate fails to build. The retirement grep only matches the literal old path, so it never sees this relative reference. The task's build_cmd is `python3 --version`, which does not build the crate, and compat.rs is not in touches, so the path policy also stops attempt 2 from fixing it.

Kind: connective. Severity: blocker.
