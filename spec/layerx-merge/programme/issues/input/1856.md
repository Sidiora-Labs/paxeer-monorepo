# Issue 1856: [Coherence] Tasks 22.39.119 and 22.39.120 now point their touches and gates at tests/agent/sdk/python, but their tests lists and capability blocks still name test files under services/agent/sdk/python/tests that do not exist

## Defect and impact

Decision 2895 moves both agent SDK repair tasks to the central test tree, and the commit rewrites their touches, build_cmd and verify_cmd to match. The tests field of each task, and all of capability.22.39.119 and capability.22.39.120 (touches, tests, verification_contract), still name services/agent/sdk/python/tests/test_evm_transaction.py, test_x402.py, test_web_search.py, test_ai_market.py and others. Those files are not in that directory; they exist only under tests/agent/sdk/python. A consumer that resolves declared tests or the capability's verification contract gets paths that collect nothing, or fail with file-not-found, which is the same misdirection the decision was written to fix.

Kind: connective. Severity: minor.
