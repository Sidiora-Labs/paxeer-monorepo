# Issue 1561: [P2] Generate the codec replay corpus before running agent vector tests

## Defect

[9b9f71f](https://github.com/Sidiora-Labs/paxeer-monorepo/commit/9b9f71f043fd795a16f6d408368c9103d1e64c59) changes the Rust corpus reader to a newly generated file, but neither tracks that file nor makes generation a prerequisite of the retained test target. Verified at main d2383df1b752967b4c27e3073a1a84bca2ab93ee.

## Source evidence

- [Corpus::load](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/d2383df1b752967b4c27e3073a1a84bca2ab93ee/services/agent/crates/layerx-types/src/vectors.rs#L138-L146) now reads tests/vectors/codec/replay_corpus.lxb.
- The [checked-in codec directory](https://github.com/Sidiora-Labs/paxeer-monorepo/tree/d2383df1b752967b4c27e3073a1a84bca2ab93ee/tests/vectors/codec) contains valid.lxv, adversarial.lxv and generate.py, but no replay_corpus.lxb.
- The [new generator](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/d2383df1b752967b4c27e3073a1a84bca2ab93ee/tests/vectors/codec/generate.py#L10-L36) writes that file.
- [make agent-test-vectors](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/d2383df1b752967b4c27e3073a1a84bca2ab93ee/Makefile#L1970-L1971) invokes Cargo directly without a generation prerequisite. Its [clock wrapper](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/d2383df1b752967b4c27e3073a1a84bca2ab93ee/tools/runtime/run-with-clock.sh) and layerx-types build.rs do not generate the corpus.
- [Vector tests](https://github.com/Sidiora-Labs/paxeer-monorepo/blob/d2383df1b752967b4c27e3073a1a84bca2ab93ee/services/agent/crates/layerx-types/tests/vectors.rs#L12-L42) load or copy the missing input before their conformance assertions.

## Expected versus actual

Expected: the supported vector-test target prepares its declared inputs and reaches conformance assertions from a clean checkout.
Actual, from static control flow: after build prerequisites are satisfied, the repository corpus test cannot load the required file; the two mutation tests fail while copying it, before testing version/class rejection. An existing locally generated file can mask this.

## Reproduction / validation (not executed)

1. Use a fresh checkout of the verified revision with the declared build toolchain/dependencies.
2. Check `git ls-files tests/vectors/codec/replay_corpus.lxb` and confirm the file is absent.
3. Run `make agent-test-vectors`; inspect corpus-load/copy failures after compilation.
4. Explicitly run `python3 tests/vectors/codec/generate.py`, then rerun to isolate the missing-input failure. This does not claim every unrelated test then passes.

## Impact

Clean-checkout testing and qualification are blocked at fixture setup. No deployed runtime impact is claimed. No tests, generators or builds were executed for this report.

## Acceptance criteria

- Track deterministic corpus bytes or generate them reproducibly before supported consuming test entry points.
- Add clean-worktree coverage without relying on an existing generated corpus.
- Preserve retired budget-pull exclusion and malformed/unsupported-version rejection checks.
