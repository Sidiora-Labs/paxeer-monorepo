# Issue 1921: [Coherence] New selectors point at manifest lines, Makefile targets and doc tokens, the same kind of label this commit retires as not a test

## Defect and impact

The commit retires dozens of selectors on the grounds that they were review labels and not declared tests, for example docs/wiki/Cli.md::wallet-estimate-fee. In the same commit it turns command-line test fields into selectors that also name no test: Cargo.toml workspace member lines, a Makefile target, a GOTCHA.kvx header and a word inside a security review doc. Several of these cannot run what their scenario asks for. Acceptance 10.1.10.1 asks for a scan for SystemTime::now and a compile of two crates, but the selector names only the KMS member line. Acceptance 13.8.4 asks for cargo metadata over seventeen workspaces, but the selector names only the platform workspace header. The parity map now treats these as test selectors that resolve, though running them proves nothing about the scenario.

Kind: semantic. Severity: minor.
