# Issue 1740: [Coherence] The test reads the consumer and membership source hashes but only checks that each is 32 bytes long, so the recorded transcript can drift from ProjectionStore without failing

## Defect and impact

The transcript embeds SHA-256 hashes of services/platform/hosted/indexer/src/ai_market.rs and ai_market_membership.rs to show which production inputs produced the recording. Both hashes match the files at this revision. transcript() never compares them with the real sources or any pinned value; it only checks their length. A later change to the consumer's promotion, refusal or recovery behaviour would leave this test green against stale bytes, which defeats the point of embedding the hashes.

Kind: connective. Severity: minor.

## Expected versus actual

Expected: The gate should compare the embedded hashes with the consumer sources, for example with include_bytes! on the two indexer files, or the platform-side regeneration test should fail when they diverge.

Actual: The hashes are informational only, so any change to the consumer leaves the recorded transcript silently stale.
