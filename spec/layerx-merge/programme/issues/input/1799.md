# Issue 1799: [Coherence] The SDK and middleware documentation still describe the old hosted routing and the /rpc adapter

## Defect and impact

The wallet SDK README and the system SDK docs still say batch() sends every px_ method except px_getReceiptKeys to hostedUrl, and that px_ reads need hostedUrl. The middleware contract still says HostedGatewayRpc requires the retired /rpc path. Both statements are false after this commit. The SDK's own error text, 'hostedUrl required for hosted px_ reads', now fires only for px_register and px_requestFunds.

Kind: connective. Severity: minor.

Reviewed commits: 6cfc7652ced4aa7499c9d02fcc6a23653a642a47

## Expected versus actual

Expected: The docs should say that px_ reads go to the node root, that only px_register and px_requestFunds need hostedUrl, and that HostedGatewayRpc posts to the gateway root.

Actual: The docs still describe the hosted px_ read routing and an adapter that requires /rpc.
