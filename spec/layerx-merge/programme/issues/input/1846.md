# Issue 1846: [Coherence] The core-suite wiring test still requires Foundry v1.7.1, so it fails now that ci.yml installs v1.8.1

## Defect and impact

The commit changes both Foundry steps in ci.yml (core and solidity jobs) from v1.7.1 to v1.8.1. tests/ci/test_core_test_all_wired.py still asserts that the core job's Foundry step inputs equal {version: v1.7.1, cache: false}. That test was not updated, so it fails at this revision. The new uniformity test passes only because it looks at the workflows and not at this older assertion.

Kind: connective. Severity: major.
