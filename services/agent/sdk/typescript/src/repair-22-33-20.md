## Compatibility

`AgentEnvelopeSurface` now supports only `gateway`, which requires an independent
`LayerXKeyCredential` as well as the existing hosted session coordinates. The
hosted request schema, authentication header, and response decoder are preserved.
The daemon mTLS request path and client key/certificate handling are removed.
For compilation of existing callers during migration, the deprecated
`AGENT_DAEMON_RPC_PATH` export is a `null` tombstone, and the deprecated daemon
constructor overload always refuses with `invalid-argument`; neither represents
a usable endpoint. Use `JsonRpcClient` for node operations at the supplied root
endpoint and `AgentEnvelopeTransport` for hosted `/v1/agent/rpc` operations.

Journal writes compare the exact durable predecessor bytes under a per-activity
exclusive filesystem lock, use unique temporary files, and sync before atomic
replacement. A stale caller receives `InvalidTransition`. Interrupted submission
recovery uses the same comparison, re-reading the winning durable state after a
race. A process killed while holding a write lock leaves that lock behind;
subsequent writes fail closed with `Journal` after bounded contention. Before
removing an abandoned lock, the storage owner must establish that no writer is
active and reconcile the durable record. The implementation never guesses that
a lock is stale or overwrites an uncertain outcome.

Gas success response limits are 16 KiB for quotes/status and 4 KiB for submission
acknowledgements. Both content-length and chunked bodies are checked before JSON
parsing, with cancellation at the limit. Mirror early-exit coverage uses the
current Node executable and a temporary script; no additional runtime, build,
credential, or installed external tool is needed.

Subscription overflow reports `SubscriptionReconciliationRequiredError` with the
last delivered cursor. Resume account-log reconciliation with node reads starting
at that block **inclusive**: several logs can share a block. Deduplicate by block
hash, transaction hash, and log index before resubscribing. Limits cover both the
number of queued notifications and their total wire bytes.
