# licenses/

License texts and third-party notices for the launchpad services, whose module
paths retain the KindleLaunch name.

## Repository and launchpad terms

The monorepo already has an [Apache-2.0 license](../../../LICENSE). Do not create
or replace that file as part of collecting launchpad notices.

The launchpad-local [LICENSE](../LICENSE) separately declares the Paxlabs
HyperPax-OS-Protocol License for the Go backend and supporting files unless their
headers or this directory specify otherwise. It includes a non-binding summary
and refers to a full text at `contracts/LICENSE`; that referenced file is absent
from this checkout. The summary is not a substitute for complete license terms.

These existing files do not resolve the applicability of the root license versus
the launchpad-local notice for every component. Approval of that boundary and
the complete applicable terms remain required before making a launchpad licensing
or redistribution claim. This page records the current notices and does not
select a new license or grant additional rights.

## Third-party notices

Keep upstream notices and any attribution-required or vendored dependency license
texts here, using the upstream SPDX identifier where available. A dependency
manifest or an SBOM entry alone does not establish redistribution permission or
satisfy notice obligations. Review the actual dependency terms and retain required
copyright and attribution text.

The [supply-chain tools](../security/supplychain/README.md) inventory dependency
licenses; `NOASSERTION` records an unknown conclusion. Completing that inventory
and any outstanding third-party notices remains separate from approving the
launchpad license boundary.
