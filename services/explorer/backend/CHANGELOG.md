# Backend release

The backend package version is **10.2.6**, as declared in [mix.exs](mix.exs).
It indexes Paxeer mainnet-beta, EVM chain ID **125** (`0x7d`), and serves the
explorer REST APIs from the indexed PostgreSQL data.

See the [backend guide](README.md) for the supported applications, native
account and transaction APIs, price feeds, configuration and build commands.
The [deployment guide](../deploy/README.md) describes the local Compose stack.
